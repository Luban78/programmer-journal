⚡ JavaScript

Krátký úvod

HTML vytváří obsah stránky a CSS určuje její vzhled.

JavaScript přidává logiku a chování. Díky němu může stránka reagovat na kliknutí, měnit text, kontrolovat vstup uživatele a ukládat data.

Všechny lekce jsou připravené. Procházet je budeme postupně naším systémem: lekce, krátký úkol, code review a ověření pochopení.

🧠 Jak přemýšlet o JavaScriptu

JavaScript přijímá hodnoty, rozhoduje se a vykonává příkazy. 


const jmeno = "Lubomír";

if (jmeno === "Lubomír") {
  console.log("Vítej v JavaScriptu!");
}

Po prvních lekcích budeš rozumět každému řádku tohoto příkladu.
