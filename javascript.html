⚡ JavaScript

Krátký úvod

JavaScript je programovací jazyk, který přidává webové stránce chování a interaktivitu.

Díky JavaScriptu může stránka reagovat na kliknutí, měnit text, kontrolovat formuláře, počítat hodnoty nebo ukládat údaje do prohlížeče.

V této kapitole budeme postupovat od jednoduchých proměnných až k práci s DOM a malým praktickým projektem.

🧠 Jak přemýšlet o JavaScript

HTML vytvoří prvky stránky a CSS určí jejich vzhled.

JavaScript je její logika – rozhoduje, co se stane po kliknutí, zadání hodnoty nebo splnění podmínky.

Příkaz const jmeno = "Lubomír"; uloží hodnotu a podmínka if rozhodne, co se má provést.
