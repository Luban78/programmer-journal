JavaScript přidává logiku a chování. Díky němu může stránka reagovat na kliknutí, měnit text, kontrolovat hodnoty a ukládat data.

V této kapitole budeme opět postupovat lekci po lekci: nejdřív vysvětlení v Programmer Journalu, potom krátký samostatný úkol a code review.

🧠 Jak přemýšlet o JavaScriptu

JavaScript bude dostávat informace, rozhodovat se a provádět příkazy. 

const jmeno = "Lubomír";

if (jmeno === "Lubomír") {
  console.log("Vítej v JavaScriptu!");
}

Nemusíš tomuto příkladu zatím rozumět. Každou jeho část postupně rozebereme.
