📗 Git

Krátký úvod

Git je systém pro správu verzí. Umožňuje ukládat změny v projektu, vracet se ke starším verzím a bezpečně spolupracovat s GitHubem.

Každý důležitý krok můžeš uložit jako commit a kdykoliv si zkontrolovat, co se v projektu změnilo.

🧠 Jak přemýšlet o Git

Git je jako ukládání hry.

git add = vybereš, co chceš uložit.

git commit = vytvoříš nový uložený bod.

git push = odešleš uložené změny na GitHub.
