📗 Git

Krátký úvod

Git je systém pro správu verzí. Umožňuje ukládat změny v projektu, vracet se ke starším verzím a bezpečně spolupracovat s GitHubem.

🧠 Jak přemýšlet o Gitu

Git je jako ukládání hry.

git add = vybereš, co chceš uložit.

git commit = vytvoříš nový save.

git push = nahraješ save na GitHub.

📚 Obsah kapitoly

  • git status
  • git add
  • git commit
  • git push
  • git pull
  • git switch
