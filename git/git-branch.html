📗 Git branch

Krátký úvod

Příkaz git branch slouží k práci s větvemi projektu.

Větev je oddělená pracovní verze projektu, ve které můžeš bezpečně vyvíjet novou funkci nebo opravu.

Hlavní větev main tak může zůstat stabilní, dokud nejsou nové změny hotové a otestované.

🧠 Jak přemýšlet o git branch

Představ si, že projekt je kniha.

Hlavní větev je originální kniha.

Nová větev je její kopie, ve které můžeš bezpečně psát, škrtat a experimentovat.

Dokud změny nesloučíš, hlavní větev zůstane beze změny.

📚 Co se dnes naučíš

  • co je větev
  • jak zobrazit lokální větve
  • jak poznat aktuální větev
  • jak vytvořit novou větev
  • jak bezpečně smazat větev
  • jak vynuceně smazat testovací větev

💻 Příklady

  • git branch

    Zobrazí seznam lokálních větví. Hvězdička označuje aktuální větev.

  • git --no-pager branch

    Zobrazí větve bez otevření pageru s prázdnými řádky označenými znakem ~.

  • git switch -c zkouska-vetve

    Vytvoří novou větev zkouska-vetve a ihned se na ni přepne.

  • git branch -d zkouska-vetve

    Bezpečně smaže větev. Git smazání odmítne, pokud by mohlo dojít ke ztrátě nesloučených změn.

  • git branch -D zkouska-vetve

    Vynutí smazání větve. Používej pouze tehdy, když víš, že změny ve větvi nepotřebuješ.

💡 Tip

Před vytvořením nové větve si vždy ověř pomocí git status, na které větvi právě jsi.

Pro názvy větví používej krátké a srozumitelné názvy bez mezer a diakritiky.

Například: oprava-navigace nebo kapitola-git-branch.

⚠️ Nejčastější chyba

Začátečník někdy smaže větev pomocí git branch -D, aniž by si ověřil její obsah.

Přepínač -D obchází bezpečnostní kontrolu Gitu a může odstranit nesloučené změny.

Nejdřív vždy zkus bezpečné git branch -d.

📝 Co si zapamatovat

  • git branch vypíše lokální větve.
  • Hvězdička označuje aktuální větev.
  • git switch -c vytvoří novou větev a přepne se na ni.
  • git branch -d bezpečně smaže větev.
  • git branch -D vynutí smazání větve.
  • main je hlavní větev projektu.
