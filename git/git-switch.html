📗 Git switch

Krátký úvod

Příkaz git switch slouží k přepínání mezi větvemi.

Díky větvím můžeš bezpečně pracovat na nových funkcích, aniž bys ovlivnil hlavní větev projektu.

Git switch také umožňuje vytvořit novou větev a rovnou se na ni přepnout.

🧠 Jak přemýšlet o git switch

Představ si, že projekt je kniha.

Hlavní větev je originální kniha.

Nová větev je její kopie, ve které můžeš bezpečně psát, škrtat a experimentovat.

Dokud změny nesloučíš, hlavní větev zůstane beze změny.

📚 Co se dnes naučíš

  • k čemu slouží git switch
  • jak přepnout větev
  • jak vytvořit novou větev
  • co je hlavní větev
  • proč používat větve

💻 Příklady

  • git switch main

    Přepne na hlavní větev projektu.

  • git switch kapitola-git-switch

    Přepne na existující větev s názvem kapitola-git-switch.

  • git switch -c kapitola-git-switch

    Vytvoří novou větev a ihned se na ni přepne.

  • git branch

    Zobrazí seznam všech lokálních větví.

💡 Tip

Pro každou větší úpravu vytvoř novou větev.

Když se něco nepovede, hlavní větev zůstane bezpečně beze změn.

⚠️ Nejčastější chyba

Začátečník někdy zapomene, na které větvi právě pracuje.

Před úpravami proto vždy spusť git status a zkontroluj název aktuální větve.

📝 Co si zapamatovat

  • git switch přepíná mezi větvemi.
  • git switch -c vytvoří novou větev.
  • main je hlavní větev projektu.
  • git branch zobrazí lokální větve.
  • Před prací je dobré ověřit aktuální větev pomocí git status.
