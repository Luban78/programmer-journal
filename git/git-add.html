📗 Git add

Krátký úvod

Příkaz git add připraví vybrané změny pro další commit.

Změny ještě neukládá natrvalo. Pouze je přesune do připravené oblasti, které se říká staging area.

🧠 Jak přemýšlet o git add

git add je jako výběr věcí, které chceš vložit do dalšího balíčku.

Soubor může být změněný, ale dokud nepoužiješ git add, nebude součástí dalšího commitu.

📚 Co se dnes naučíš

  • co dělá git add
  • co je staging area
  • jak přidat jeden soubor
  • jak přidat všechny změny
  • jak zkontrolovat připravené soubory

💻 Příklady

  • git add index.html

    Připraví pro commit pouze soubor index.html.

  • git add index.html style.css

    Připraví pro commit oba uvedené soubory.

  • git add .

    Připraví všechny změněné a nové soubory v aktuálním projektu.

💡 Tip

Po příkazu git add vždy spusťgit status .

Zkontroluješ tak, které soubory jsou opravdu připravené pro commit.

⚠️ Nejčastější chyba

Začátečník někdy použije git commit bez předchozího git add.

Příkaz git add . může připravit i soubor, který jsi přidat nechtěl.

Proto je důležité před commitem zkontrolovat git status.

Git potom nové změny do commitu nezahrne.

📝 Co si zapamatovat

  • git add nepřidává soubor na GitHub.
  • git add ještě nevytváří commit.
  • git add připravuje změny pro commit.
  • git add název-souboru připraví jeden soubor.
  • git add . připraví všechny změny.

💻 Vyzkoušej si

jeden soubor:

git status
git add index.html
git status

všechny soubory:

git add .
git status
