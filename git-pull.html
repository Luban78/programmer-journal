📗 Git pull

Krátký úvod

Příkaz git pull stáhne nejnovější změny z GitHubu do počítače.

Používá se hlavně tehdy, když byl projekt upraven na jiném zařízení nebo jiným člověkem.

Git pull pomáhá udržovat lokální projekt synchronizovaný se vzdáleným repozitářem.

🧠 Jak přemýšlet o git pull

Git pull je jako stažení nejnovější uložené hry z cloudu.

Pokud jsi pracoval na mobilu a potom pokračuješ na počítači, musíš nejdřív stáhnout změny z GitHubu.

Tím dostaneš na druhé zařízení stejnou verzi projektu.

💻 Příklady

  • git pull

    Stáhne nové commity z GitHubu a začlení je do aktuální větve.

  • git status

    Před stažením ověří, zda v projektu nemáš neuložené lokální změny.

  • git pull origin main

    Stáhne změny z větve main vzdáleného repozitáře origin.

💡 Tip

Před příkazem git pull vždy spusť git status.

Nejbezpečnější je stahovat změny ve chvíli, kdy je pracovní strom čistý.

Když přecházíš mezi mobilem a počítačem, začni práci příkazem git pull.

⚠️ Nejčastější chyba

Začátečník někdy spustí git pull, i když má v projektu neuložené změny.

Lokální změny se potom mohou smíchat se změnami z GitHubu nebo může vzniknout konflikt.

Nejdřív změny commitni, odlož nebo vrať. Teprve potom použij git pull.

📝 Co si zapamatovat

  • git pull stáhne změny z GitHubu.
  • git pull pracuje s aktuální větví.
  • Před pull je vhodné spustit git status.
  • Nejbezpečnější je čistý pracovní strom.
  • Already up to date znamená, že žádné nové změny nejsou.
  • Při práci na více zařízeních používej git pull před začátkem práce.
