🌐 HTML

Krátký úvod

HTML je značkovací jazyk, který vytváří základní strukturu webové stránky.

Pomocí HTML určujeme, co se na stránce nachází – například nadpisy, odstavce, obrázky, odkazy, seznamy, tlačítka nebo formuláře.

HTML neřeší vzhled stránky ani její chování. Vzhled později upravuje CSS a interaktivitu přidává JavaScript.

🧠 Jak přemýšlet o HTML

Představ si webovou stránku jako dům.

HTML tvoří jeho základní konstrukci – stěny, místnosti, dveře a okna.

CSS později určí barvy, velikosti a vzhled domu.

JavaScript do něj přidá funkce, například rozsvícení světla po stisknutí vypínače.
