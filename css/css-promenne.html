🎛️ CSS proměnné a opakované hodnoty

Krátký úvod

Ve větším CSS souboru se stejné barvy, mezery nebo rozměry často opakují na mnoha místech.

CSS proměnná umožní hodnotu pojmenovat a potom ji opakovaně používat.

Když později hodnotu změníš na jednom místě, změna se projeví ve všech pravidlech, která proměnnou používají.

🧠 Jak o tom přemýšlet

Místo opakování konkrétní barvy: 

color: #334f9c;
border: 3px solid #334f9c;
background-color: #334f9c;

ji pojmenuješ například: 

--hlavni-barva: #334f9c;

A potom používáš její jméno: 

color: var(--hlavni-barva);

📚 Co se dnes naučíš

  • vytvořit CSS proměnnou
  • použít ji pomocí funkce var()
  • uložit barvy, mezery i rozměry
  • vytvořit společné proměnné v selektoru :root
  • pochopit místní platnost proměnné
  • použít záložní hodnotu
  • rychle změnit barevné téma stránky
  • pochopit rozdíl mezi CSS proměnnou a budoucí JavaScript proměnnou

1️⃣ Vytvoření CSS proměnné

:root {
  --hlavni-barva: #334f9c;
}

Název vlastní CSS proměnné vždy začíná dvěma pomlčkami: 

--nazev-promenne

Za dvojtečku zapisujeme hodnotu stejně jako u běžné CSS vlastnosti.

2️⃣ Použití pomocí var()

h1 {
  color: var(--hlavni-barva);
}

Funkce var() načte hodnotu uloženou v proměnné.

3️⃣ Proč používáme :root

:root {
  --hlavni-barva: #334f9c;
  --pozadi-stranky: #e7edf8;
  --mezera: 16px;
}

Selektor :root představuje kořen dokumentu.

Proměnné vytvořené v :root mohou používat prvky v celé stránce.

💡 Co se do :root často ukládá

  • hlavní a vedlejší barvy,
  • barvy pozadí a textu,
  • opakované mezery,
  • velikost zaoblení,
  • maximální šířka obsahu.

4️⃣ Proměnná nemusí obsahovat jen barvu

:root {
  --mezera-mala: 8px;
  --mezera-velka: 24px;
  --zaobleni: 16px;
  --sirka-karty: 420px;
}
.karta {
  max-width: var(--sirka-karty);
  padding: var(--mezera-velka);
  border-radius: var(--zaobleni);
}

Proměnná může uchovávat téměř jakoukoliv CSS hodnotu.

5️⃣ Kompletní barevná sada

:root {
  --barva-hlavni: #334f9c;
  --barva-vedlejsi: #6f42c1;
  --barva-textu: #252535;
  --barva-pozadi: #e7edf8;
  --barva-karty: #ffffff;
}
body {
  color: var(--barva-textu);
  background-color: var(--barva-pozadi);
}

.karta {
  background-color: var(--barva-karty);
  border: 3px solid var(--barva-hlavni);
}

h1 {
  color: var(--barva-hlavni);
}

Celé barevné téma je nyní přehledně uložené na jednom místě.

6️⃣ Záložní hodnota

h1 {
  color: var(--hlavni-barva, darkblue);
}

Pokud proměnná --hlavni-barva neexistuje, použije se záložní hodnota darkblue.

🧠 Čtení vlastními slovy

Použij hlavní barvu. Jestli není dostupná, použij tmavě modrou.

7️⃣ Místní proměnná

.upozorneni {
  --barva-bloku: orange;

  color: var(--barva-bloku);
  border-left: 6px solid var(--barva-bloku);
}

Proměnná vytvořená uvnitř .upozorneni je dostupná tomuto prvku a jeho potomkům.

Ostatní části stránky ji běžně použít nemohou.

8️⃣ Přepsání proměnné v určité části

:root {
  --hlavni-barva: #334f9c;
}

.varovani {
  --hlavni-barva: #b3261e;
}
.karta {
  border: 3px solid var(--hlavni-barva);
}

Běžná karta použije modrou barvu. Karta uvnitř prvku .varovani použije červenou.

9️⃣ Jednoduché světlé a tmavé téma

:root {
  --pozadi: #f3f5fa;
  --text: #252535;
  --karta: #ffffff;
}

.tmave-tema {
  --pozadi: #17171d;
  --text: #f3f3f7;
  --karta: #292933;
}
body {
  color: var(--text);
  background-color: var(--pozadi);
}

.karta {
  background-color: var(--karta);
}

Zatím můžeme třídu tmave-tema přidat ručně v HTML.

Později ji pomocí JavaScriptu budeme přepínat po kliknutí na tlačítko.

💡 Most k JavaScriptu

JavaScript může měnit třídy prvků. CSS proměnné potom umožní jednou změnou třídy přebarvit celé téma.

🔟 CSS proměnná není JavaScript proměnná

:root {
  --barva: blue;
}
const barva = "blue";

Oba zápisy ukládají hodnotu pod názvem, ale patří do jiných jazyků a používají se jinak.

  • CSS proměnná řídí hlavně vzhled.
  • JavaScript proměnná uchovává data pro logiku programu.

💻 Kompletní příklad

Soubor index.html

Soubor style.css

:root {
  --hlavni-barva: #334f9c;
  --vedlejsi-barva: #6f42c1;
  --pozadi: #e7edf8;
  --karta: #ffffff;
  --text: #252535;

  --mezera: 20px;
  --zaobleni: 16px;
}

body {
  min-height: 100vh;
  margin: 0;

  display: flex;
  justify-content: center;
  align-items: center;

  color: var(--text);
  background-color: var(--pozadi);
  font-family: Arial, sans-serif;
}

.karta {
  box-sizing: border-box;
  width: 90%;
  max-width: 420px;

  padding: var(--mezera);
  border: 3px solid var(--hlavni-barva);
  border-radius: var(--zaobleni);

  background-color: var(--karta);
}

h1 {
  color: var(--hlavni-barva);
  text-align: center;
}

button {
  padding: 10px 18px;
  border: 2px solid var(--vedlejsi-barva);
  border-radius: calc(var(--zaobleni) / 2);

  color: white;
  background-color: var(--vedlejsi-barva);
}

⚠️ Nejčastější chyby

  • Název proměnné nezačíná dvěma pomlčkami.
  • Proměnná se použije bez funkce var().
  • V názvu proměnné je překlep.
  • Místní proměnná se používá mimo oblast, ve které byla vytvořena.
  • Všechny jednotlivé hodnoty se změní na proměnné, i když se nikde neopakují a nemají žádný významný název.

📝 Co si zapamatovat

  • Název CSS proměnné začíná dvěma pomlčkami.
  • Hodnotu načítáme pomocí var(--nazev).
  • Společné proměnné je praktické ukládat do :root.
  • CSS proměnná může obsahovat barvu, mezeru, rozměr i další hodnoty.
  • Druhá hodnota ve var() slouží jako záloha.
  • Proměnnou lze v určité části stránky přepsat.
  • CSS proměnné usnadňují barevná témata a budoucí změny pomocí JavaScriptu.

⏭️ Co bude následovat

Po nastudování dostaneš krátký úkol: vytvoříš tři společné proměnné a použiješ je na kartě a tlačítku.

Potom přijde závěrečný CSS projekt.
