✨ Pozadí, okraje, zaoblení a stíny

Krátký úvod

Rozložení prvků už umíš řídit pomocí rozměrů, box modelu a Flexboxu.

Teď se zaměříme na jejich vzhled. Z obyčejného obdélníku vytvoříš kartu, tlačítko nebo upozornění, které bude na stránce působit výrazněji.

Budeme pracovat hlavně s pozadím, okrajem, zaoblením a stínem.

🧠 Jak o tom přemýšlet

Při úpravě prvku si postupně polož čtyři otázky:

  1. Jaké má mít pozadí?
  2. Má mít viditelný okraj?
  3. Mají být rohy ostré, nebo zaoblené?
  4. Má prvek působit vystouple pomocí stínu?

Jednotlivé vlastnosti nejsou složité. Důležitá je jejich rozumná kombinace.

📚 Co se dnes naučíš

  • nastavit jednobarevné pozadí
  • pochopit rozdíl mezi background-color a background
  • vytvořit různé druhy okrajů
  • nastavit okraj pouze na vybrané straně
  • zaoblit všechny rohy nebo každý roh jinak
  • vytvořit kruh pomocí border-radius: 50%
  • pochopit jednotlivé části vlastnosti box-shadow
  • použít jemný, výrazný nebo vnitřní stín
  • přidat stín textu

1️⃣ Background-color – barva pozadí

Barvu pozadí prvku nastavuje vlastnost background-color. 

.karta {
  background-color: #ffffff;
}

Pozadí se zobrazí pod obsahem a paddingem prvku. Margin leží mimo prvek, takže barvu pozadí nemá.

Zkrácená vlastnost background

.karta {
  background: #ffffff;
}

Pro samotnou barvu fungují oba zápisy.

💡 Který zápis použít

Když nastavuješ jen barvu, je background-color přesnější a lépe říká, co se mění.

Zkrácená vlastnost background se později hodí také pro obrázky nebo barevné přechody.

2️⃣ Jednoduchý barevný přechod

Místo jedné barvy může pozadí plynule přecházet mezi dvěma odstíny. 

.hlavicka {
  background: linear-gradient(
    to right,
    #3457d5,
    #6f42c1
  );
}

Hodnota to right určuje směr zleva doprava.

Barevný přechod je užitečný pro výraznou hlavičku nebo tlačítko, ale není vhodné jím přeplnit celou stránku.

3️⃣ Border – okraj prvku

Okraj zapisujeme nejčastěji zkrácenou vlastností: 

.karta {
  border: 3px solid #334f9c;
}

Zápis obsahuje tři části:

  • 3px – tloušťka,
  • solid – druh čáry,
  • #334f9c – barva.

Základní druhy čáry

.plny {
  border: 3px solid #333333;
}

.carkovany {
  border: 3px dashed #333333;
}

.teckovany {
  border: 3px dotted #333333;
}

.dvojity {
  border: 6px double #333333;
}
  • solid – plná čára,
  • dashed – čárkovaná,
  • dotted – tečkovaná,
  • double – dvojitá.

⚠️ Pozor na překlep v selektoru

Název třídy musí začínat tečkou: .teckovany.

Bez tečky by CSS hledalo HTML značku s názvem <teckovany>.

4️⃣ Okraj pouze na jedné straně

.upozorneni {
  border-left: 6px solid orange;
}

Stejným způsobem můžeš použít:

  • border-top
  • border-right
  • border-bottom
  • border-left

Výrazný levý okraj se často používá u tipů, chybových hlášení nebo poznámek.

5️⃣ Border-radius – zaoblení rohů

Vlastnost border-radius zaobluje rohy prvku. 

.karta {
  border-radius: 16px;
}

Čím vyšší hodnota, tím kulatější rohy budou.

Čtyři různé rohy

.karta {
  border-radius: 10px 20px 30px 40px;
}

Hodnoty se čtou v tomto pořadí:

  1. levý horní roh,
  2. pravý horní roh,
  3. pravý dolní roh,
  4. levý dolní roh.

Kruh

.avatar {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}

Kruh vznikne jen tehdy, když má prvek stejnou šířku a výšku. Z obdélníku by vznikl ovál.

6️⃣ Box-shadow – stín prvku

.karta {
  box-shadow: 5px 5px 12px #777777;
}

Hodnoty znamenají:

  1. vodorovný posun stínu,
  2. svislý posun stínu,
  3. rozmazání,
  4. barvu stínu.
box-shadow: 5px 5px 12px gray;
            ─── ─── ──── ────
             X   Y  blur  barva

Jemný stín

.karta {
  box-shadow: 0 4px 12px #999999;
}

Nulový vodorovný posun znamená, že stín nebude posunutý doprava ani doleva.

Stín na opačnou stranu

.karta {
  box-shadow: -5px -5px 12px #777777;
}

Záporné hodnoty posunou stín vlevo a nahoru.

7️⃣ Roztažení stínu

Mezi rozmazání a barvu můžeš přidat ještě hodnotu roztažení. 

.karta {
  box-shadow: 0 4px 12px 3px #999999;
}

Pořadí je nyní:

  1. vodorovný posun,
  2. svislý posun,
  3. rozmazání,
  4. roztažení,
  5. barva.

💡 Méně bývá více

Velmi tmavý a ostrý stín může působit těžce. U běžných karet většinou vypadá lépe jemnější stín s větším rozmazáním.

8️⃣ Vnitřní stín

Klíčové slovo inset vytvoří stín uvnitř prvku. 

.tlacitko {
  box-shadow: inset 0 0 8px #555555;
}

Prvek potom může působit vtlačeně nebo prohloubeně.

9️⃣ Více stínů současně

Jednotlivé stíny můžeš oddělit čárkou: 

.karta {
  box-shadow:
    0 4px 12px #888888,
    inset 0 0 5px #dddddd;
}

První stín je vnější a druhý je vnitřní.

🔟 Text-shadow – stín textu

h1 {
  text-shadow: 2px 2px 4px #999999;
}

Pořadí hodnot je podobné jako u stínu prvku:

  1. vodorovný posun,
  2. svislý posun,
  3. rozmazání,
  4. barva.

⚠️ Nepřeháněj textový stín

Příliš silný stín může snížit čitelnost. Nejlépe funguje jako jemné zvýraznění nadpisu.

🔍 Jak jednotlivé vlastnosti spolupracují

  • Pozadí oddělí kartu od stránky.
  • Border přesně vymezí její okraj.
  • Border-radius změkčí ostré rohy.
  • Box-shadow vytvoří dojem, že karta leží nad stránkou.
  • Text-shadow jemně zvýrazní nadpis.

⚠️ Nejčastější chyby

  • U borderu chybí jednotka: border: 3 solid blue;.
  • U borderu chybí druh čáry: border: 3px blue;.
  • Kruh nevznikne, protože prvek nemá stejnou šířku a výšku.
  • Hodnoty stínu jsou v nesprávném pořadí.
  • Stín je příliš tmavý, ostrý nebo velký a přebíjí obsah.
  • Příliš mnoho různých barev, okrajů a stínů vytvoří nepřehledný vzhled.

📝 Co si zapamatovat

  • background-color nastavuje barvu pozadí.
  • background je zkrácená vlastnost a umožňuje také barevný přechod.
  • border obsahuje tloušťku, druh čáry a barvu.
  • border-radius zaobluje rohy.
  • border-radius: 50%; vytvoří kruh pouze ze čtvercového prvku.
  • box-shadow vytváří stín celého prvku.
  • Klíčové slovo inset vytvoří vnitřní stín.
  • text-shadow vytváří stín textu.
