📱 Responzivní design a media queries

Krátký úvod

Stejnou webovou stránku mohou lidé otevřít na telefonu, tabletu, notebooku i velkém monitoru.

Responzivní design znamená, že se vzhled stránky přizpůsobí dostupné šířce obrazovky a zůstane použitelný na různých zařízeních.

V předchozích lekcích ses na responzivitu už připravoval pomocí procent, max-width, flex-wrap a pružných rozměrů. Teď se naučíš pomocí media queries měnit pravidla podle šířky obrazovky.

🧠 Jak o tom přemýšlet

Nejprve vytvoříš základní vzhled, který funguje na malé obrazovce.

Potom prohlížeči řekneš:

„Když bude obrazovka alespoň takto široká, použij navíc tato pravidla.“

K tomu slouží @media.

📚 Co se dnes naučíš

  • co znamená responzivní web
  • proč je důležitý viewport v HTML
  • jak se zapisuje media query
  • jak funguje min-width
  • jak funguje max-width
  • co znamená mobile-first přístup
  • jak na větší obrazovce změnit Flexbox z column na row
  • jak měnit mezery, písmo a rozměry podle šířky obrazovky
  • jak vybrat breakpoint podle skutečného vzhledu stránky

1️⃣ Viewport v HTML

V části <head> už pravidelně používáš tento řádek: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Říká mobilnímu prohlížeči, aby šířku stránky přizpůsobil skutečné šířce zařízení.

Bez správného viewportu může stránka na telefonu vypadat zmenšeně jako široká počítačová stránka.

💡 Praktické pravidlo

Tento meta řádek nechávej ve všech běžných responzivních stránkách.

2️⃣ Co už je responzivní bez media query

Ne každá responzivní úprava potřebuje @media. 

.karta {
  box-sizing: border-box;
  width: 90%;
  max-width: 420px;
  margin: 20px auto;
}

Na malém telefonu se karta zmenší na 90 % dostupného prostoru. Na velké obrazovce nepřeroste přes 420 px.

Také Flexbox může prvky automaticky zalamovat: 

.stitky {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

Media query používáme až tehdy, když chceme při určité šířce skutečně změnit rozložení nebo vzhled.

3️⃣ Základní zápis media query

@media (min-width: 700px) {
  .karta {
    max-width: 650px;
  }
}

Pravidlo uvnitř se použije pouze tehdy, když je okno široké alespoň 700 px.

🧠 Čtení vlastními slovy

@media: použij podmíněná pravidla.

min-width: 700px: když je šířka nejméně 700 px.

Složené závorky obsahují CSS, které se za této podmínky přidá nebo přepíše.

4️⃣ Mobile-first přístup

Mobile-first znamená, že základní CSS nejprve navrhneš pro malou obrazovku.

Potom pomocí min-width přidáváš změny pro větší obrazovky. 

.obsah {
  display: flex;
  flex-direction: column;
  gap: 15px;
}

@media (min-width: 700px) {
  .obsah {
    flex-direction: row;
  }
}

Na telefonu budou části pod sebou:

[ první část ]
[ druhá část ]

Od šířky 700 px budou vedle sebe:

[ první část ] [ druhá část ]

💡 Proč je mobile-first praktický

Začneš jednodušším rozložením pro malý prostor a větší obrazovky potom postupně rozšiřuješ.

5️⃣ Min-width a max-width v media query

Min-width

@media (min-width: 700px) {
  h1 {
    font-size: 2.5rem;
  }
}

Pravidlo platí od 700 px výše.

Max-width

@media (max-width: 699px) {
  h1 {
    font-size: 1.7rem;
  }
}

Pravidlo platí do šířky 699 px včetně.

🧠 Nezaměňovat dvě různá použití

U běžného prvku: max-width: 420px; omezuje šířku samotného prvku.

V media query: @media (max-width: 699px) kontroluje šířku okna, při které se mají pravidla použít.

6️⃣ Změna Flexboxu podle obrazovky

HTML

CSS

.karty {
  display: flex;
  flex-direction: column;
  gap: 15px;
}

@media (min-width: 750px) {
  .karty {
    flex-direction: row;
  }
}

Základní styl skládá karty pod sebe. Na větší obrazovce se změní pouze směr jejich rodiče.

⚠️ Flexbox stále nastavujeme rodiči

Media query nemění hlavní pravidlo Flexboxu. Jestli chceš přeskupit karty, upravuješ jejich společného rodiče.

7️⃣ Změna více vlastností současně

.karta {
  padding: 16px;
}

h1 {
  font-size: 1.8rem;
}

@media (min-width: 800px) {
  .karta {
    padding: 30px;
  }

  h1 {
    font-size: 2.6rem;
  }
}

Na větším displeji můžeš využít více prostoru: zvětšit padding, písmo nebo maximální šířku.

Nemusíš ale měnit vše. Media query má obsahovat jen vlastnosti, které se skutečně potřebují změnit.

8️⃣ Breakpoint – bod změny

Číslo v podmínce, například 700 px, se označuje jako breakpoint. 

@media (min-width: 700px) {
  /* změny pro širší obrazovku */
}

Breakpoint není přesný název konkrétního telefonu nebo tabletu.

Vyber ho podle chvíle, kdy se tvoje rozložení začne nevejít nebo kdy už naopak vznikne dost prostoru pro jiný vzhled.

💡 Správný způsob testování

Pomalu měň šířku náhledu a sleduj, kde stránka přestává vypadat dobře. Tam je vhodné zvážit breakpoint.

9️⃣ Více breakpointů

.karta {
  padding: 14px;
}

@media (min-width: 600px) {
  .karta {
    padding: 22px;
  }
}

@media (min-width: 1000px) {
  .karta {
    padding: 32px;
  }
}

Pravidla se postupně přidávají. Při šířce nad 1000 px platí základní CSS i obě media queries.

🧠 Rozhoduje také pořadí

Když více pravidel upravuje stejnou vlastnost a mají stejnou sílu selektoru, pozdější pravidlo přepíše předchozí.

Přesné fungování pořadí a specificity probereme v další lekci.

🔟 Co nedělat

⚠️ Nejčastější chyby

  • Chybí viewport v HTML.
  • Media query je vložená dovnitř jiného CSS pravidla.
  • Chybí některá složená závorka.
  • Použije se příliš mnoho breakpointů bez skutečného důvodu.
  • Rozložení se navrhuje pro konkrétní model telefonu místo podle prostoru, který obsah potřebuje.
  • Na mobilu zůstane pevná šířka větší než obrazovka.
  • Pevná výška zabrání kartě růst podle obsahu.
  • Změní se jednotlivé flex položky, i když bylo potřeba změnit jejich společného rodiče.

💻 Kompletní příklad

Soubor index.html

Soubor style.css

body {
  margin: 0;
  padding: 20px;

  background-color: #e7edf8;
  color: #252535;
  font-family: Arial, sans-serif;
}

main {
  width: 100%;
  max-width: 1000px;
  margin: 0 auto;
}

h1 {
  font-size: 1.8rem;
  text-align: center;
  color: #334f9c;
}

.karty {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

.karta {
  box-sizing: border-box;
  width: 100%;

  padding: 18px;
  border: 3px solid #334f9c;
  border-radius: 14px;

  background-color: white;
  box-shadow: 0 5px 12px #a6afc2;
}

@media (min-width: 750px) {
  body {
    padding: 35px;
  }

  h1 {
    font-size: 2.5rem;
  }

  .karty {
    flex-direction: row;
  }

  .karta {
    width: 33%;
  }
}

🔍 Co se v příkladu mění

  • Na malé obrazovce jsou karty pod sebou.
  • Od šířky 750 px jsou karty vedle sebe.
  • Na větší obrazovce se zvětší padding stránky i hlavní nadpis.
  • Všechny změny jsou soustředěné v jedné media query.

📝 Co si zapamatovat

  • Responzivní stránka se přizpůsobuje dostupnému prostoru.
  • Viewport v HTML je důležitý pro správné zobrazení na mobilu.
  • Nejdřív používej pružné rozměry, max-width a flex-wrap.
  • Media query používej pro změnu rozložení nebo vzhledu při určité šířce.
  • Mobile-first začíná základními styly pro malou obrazovku.
  • @media (min-width: ...) přidává změny od dané šířky výše.
  • Breakpoint vybírej podle obsahu a vzhledu, ne podle konkrétní značky zařízení.
  • Do media query zapisuj pouze to, co se má změnit.

⏭️ Co bude následovat

Úkol bude rozdělený do malých částí a kontrolní otázky dostaneš postupně po jedné.
