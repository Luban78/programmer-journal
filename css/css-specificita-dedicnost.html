⚖️ Specificita, dědičnost a pořadí pravidel

Krátký úvod

Na jeden HTML prvek může současně mířit několik CSS pravidel.

Prohlížeč proto musí rozhodnout, které pravidlo má přednost. Toto rozhodování ovlivňuje specificita selektoru, pořadí pravidel a někdy také dědičnost.

Díky této lekci pochopíš, proč se někdy barva nebo jiná vlastnost nezmění tak, jak očekáváš.

🧠 Jak o tom přemýšlet

Když se dvě CSS pravidla přou o stejnou vlastnost, prohlížeč hledá silnější a přesnější pravidlo.

Zjednodušeně platí:

element  <  třída  <  ID

p        <  .text  <  #upozorneni

Pokud mají pravidla stejnou sílu, vyhraje pravidlo, které je v CSS napsané později.

📚 Co se dnes naučíš

  • co znamená CSS kaskáda
  • jak funguje pořadí pravidel
  • proč je třída silnější než element
  • proč je ID silnější než třída
  • co znamená dědičnost
  • které vlastnosti se často dědí
  • jak fungují hodnoty inherit a initial
  • proč se má !important používat jen výjimečně

1️⃣ Kaskáda a pořadí pravidel

p {
  color: blue;
}

p {
  color: red;
}

Obě pravidla používají stejný selektor p.

Proto mají stejnou sílu a vyhraje pozdější pravidlo. Odstavce budou červené.

💡 Praktické pravidlo

Když jsou selektory stejně silné, pozdější pravidlo přepíše předchozí.

2️⃣ Element, třída a ID

HTML

CSS

p {
  color: green;
}

.dulezity {
  color: blue;
}

#upozorneni {
  color: red;
}

Na jeden odstavec míří všechna tři pravidla. Vyhraje ID a text bude červený. 

p  → obecné pravidlo
.dulezity → přesnější pravidlo
#upozorneni → nejpřesnější z těchto tří

🧠 Jednoduchá pomůcka

Element vybírá celý druh prvků.

Třída vybírá určitou skupinu.

ID vybírá jeden konkrétní prvek. Proto je jeho selektor přesnější.

3️⃣ Složené selektory

.karta p {
  color: darkblue;
}

Toto pravidlo vybírá pouze odstavce uvnitř prvku s třídou karta.

Selektor je přesnější než samotné p, protože obsahuje třídu i element.

4️⃣ Dědičnost

Některé CSS vlastnosti se automaticky přenášejí z rodiče na jeho potomky.

HTML

CSS

.karta {
  color: darkblue;
  font-family: Arial, sans-serif;
}

Nadpis i odstavec zdědí barvu textu a rodinu písma, pokud nemají vlastní pravidlo.

Vlastnosti, které se často dědí

  • color
  • font-family
  • font-size
  • font-weight
  • line-height
  • text-align

Vlastnosti, které se běžně nedědí

  • margin
  • padding
  • border
  • background-color
  • width
  • height

🧠 Proč je to užitečné

Když nastavíš písmo a základní barvu na <body>, nemusíš je opakovat u každého odstavce a nadpisu.

5️⃣ Vlastní pravidlo přepíše zděděnou hodnotu

.karta {
  color: darkblue;
}

.karta h2 {
  color: darkred;
}

Odstavec zdědí tmavě modrou barvu. Nadpis má ale vlastní pravidlo, takže bude tmavě červený.

6️⃣ Hodnota inherit

Hodnota inherit výslovně převezme hodnotu od rodiče. 

.karta {
  border: 3px solid darkblue;
}

.vnitrni {
  border: inherit;
}

Border se běžně nedědí. Pomocí inherit ho ale vnitřnímu prvku předáme úmyslně.

7️⃣ Hodnota initial

Hodnota initial vrátí vlastnost na její výchozí CSS hodnotu. 

.karta {
  color: blue;
}

.bez-barvy-rodice {
  color: initial;
}

Potomek nebude používat modrou barvu zděděnou od karty.

8️⃣ Inline styl

Styl přímo v HTML má vysokou prioritu. Pro běžnou práci ho ale používat nechceme, protože míchá obsah a vzhled dohromady.

⚠️ Proč se inline stylu vyhýbat

Údržba stránky je potom složitější a stejné hodnoty musíš měnit na více místech.

Pro naše projekty budeme dál používat samostatný soubor style.css.

9️⃣ !important

p {
  color: red !important;
}

Klíčové slovo !important dá danému pravidlu velmi vysokou prioritu.

⚠️ Používej pouze výjimečně

Časté používání !important vede k těžko opravitelnému CSS.

Nejdřív zkontroluj selektor, pořadí pravidel a případnou dědičnost.

Soubor style.css

}

📝 Co si zapamatovat

  • Když mají selektory stejnou sílu, vyhraje pozdější pravidlo.
  • Zjednodušeně platí: element je slabší než třída a třída je slabší než ID.
  • Textové vlastnosti se často dědí z rodiče na potomky.
  • Rozměry, margin, padding, border a pozadí se běžně nedědí.
  • Vlastní pravidlo potomka přepíše zděděnou hodnotu.
  • !important není běžné řešení konfliktu.
