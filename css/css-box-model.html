📦 Box model: obsah, padding, border a margin

Krátký úvod

Každý HTML prvek si můžeš představit jako obdélníkovou krabici.

Uvnitř krabice je obsah. Kolem obsahu může být vnitřní odsazení, okraj a vnější odsazení.

Tento způsob výpočtu prostoru se nazývá CSS box model.

🧠 Jak o tom přemýšlet

Představ si zabalený dárek:

  • content je samotný dárek,
  • padding je výplň kolem dárku,
  • border je krabice,
  • margin je volné místo kolem celé krabice.

V CSS nejčastěji pracujeme se třemi vlastnostmi: padding, border a margin.

1️⃣ Content – obsah

Obsah je to, co se nachází uvnitř HTML prvku.

U odstavce je obsahem text. U obrázku je obsahem obrázek. U tlačítka je obsahem jeho text.

Barvu pozadí prvku už znáš: 

p {
  background-color: lightblue;
}

Pozadí se zobrazí pod obsahem a také pod paddingem, pokud ho přidáme.

2️⃣ Padding – vnitřní odsazení

Vlastnost padding vytváří prostor uvnitř prvku mezi obsahem a okrajem. 

p {
  background-color: lightblue;
  padding: 20px;
}

Text už nebude nalepený na okraj barevného pozadí. Kolem textu vznikne uvnitř prvku volný prostor.

💡 Jak poznat padding

Když má prvek barvu pozadí, padding tuto barevnou plochu zvětší.

Jednotlivé strany paddingu

.karta {
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 30px;
  padding-left: 40px;
}

Každou stranu můžeš nastavit samostatně.

Zkrácený zápis paddingu

.karta {
  padding: 10px 20px 30px 40px;
}

Hodnoty se čtou po směru hodinových ručiček:

  1. nahoře
  2. vpravo
  3. dole
  4. vlevo

Častý zápis se dvěma hodnotami:

.karta {
  padding: 10px 20px;
}
  • první hodnota nastaví horní a dolní odsazení,
  • druhá hodnota nastaví levé a pravé odsazení.

3️⃣ Border – okraj

Vlastnost border vytvoří viditelný okraj kolem obsahu a paddingu. 

.karta {
  border: 3px solid darkblue;
}

Zápis obsahuje tři části:

  • 3px – tloušťka okraje,
  • solid – styl čáry,
  • darkblue – barva okraje.

Další základní styly okraje

.prvni {
  border: 2px solid black;
}

.druhy {
  border: 2px dashed black;
}

.treti {
  border: 2px dotted black;
}
  • solid – plná čára,
  • dashed – čárkovaná čára,
  • dotted – tečkovaná čára.

Okraj pouze na jedné straně

.poznamka {
  border-left: 5px solid orange;
}

Podobně můžeš použít border-top, border-right nebo border-bottom.

4️⃣ Margin – vnější odsazení

Vlastnost margin vytváří prostor vně prvku, za jeho okrajem. 

.karta {
  margin: 20px;
}

Margin oddálí celý prvek od sousedních prvků nebo od okraje stránky.

💡 Jak poznat margin

Margin není součástí barevného pozadí prvku. Je to prázdný prostor mimo prvek.

Jednotlivé strany marginu

.karta {
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 30px;
  margin-left: 40px;
}

Zkrácený zápis marginu

.karta {
  margin: 10px 20px 30px 40px;
}

Pořadí je stejné jako u paddingu: nahoře, vpravo, dole, vlevo.

🔍 Padding a margin vedle sebe

.karta {
  background-color: lightblue;
  padding: 20px;
  border: 3px solid darkblue;
  margin: 30px;
}
  • padding: 20px; vytvoří prostor uvnitř karty.
  • border: 3px solid darkblue; vytvoří okraj kolem karty.
  • margin: 30px; oddálí kartu od okolí.

🧠 Nejdůležitější rozdíl

Padding je uvnitř.

Margin je venku.

💻 Kompletní příklad

Soubor index.html

Soubor style.css

body {
  background-color: #e8e8f0;
  font-family: Arial, sans-serif;
}

.karta {
  background-color: white;
  color: #303038;

  padding: 20px;
  border: 4px solid #3f51b5;
  margin: 30px;
}

h1 {
  color: #3f51b5;
  text-align: center;
}

V tomto příkladu je text obsahem karty. Padding vytvoří prostor mezi textem a okrajem. Border vytvoří modrý okraj. Margin oddálí kartu od okrajů stránky.

🧪 Jak si rozdíl bezpečně ověřit

Když si nejsi jistý, použij výraznou barvu pozadí a okraj: 

.test {
  background-color: yellow;
  padding: 20px;
  border: 5px solid red;
  margin: 30px;
}

Žlutá plocha ukáže obsah a padding. Červená čára ukáže border. Prázdný prostor za červenou čárou je margin.

⚠️ Nejčastější chyby

  • Padding a margin se zamění. Pamatuj: padding je uvnitř, margin venku.
  • U hodnoty chybí jednotka: padding: 20;. Správně je padding: 20px;.
  • U borderu chybí styl čáry: border: 2px red;. Správně například border: 2px solid red;.
  • U čtyř hodnot se zamění pořadí. Čti je: nahoře, vpravo, dole, vlevo.
  • Očekává se, že margin změní barvu pozadí prvku. Margin je ale mimo prvek a barvu pozadí nemá.

📝 Co si zapamatovat

  • Každý HTML prvek se chová jako obdélníková krabice.
  • content je obsah prvku.
  • padding je prostor uvnitř mezi obsahem a okrajem.
  • border je viditelný okraj prvku.
  • margin je prostor vně prvku.
  • Jednotlivé strany můžeš nastavit pomocí -top, -right, -bottom a -left.
  • Čtyři zkrácené hodnoty se čtou: nahoře, vpravo, dole, vlevo.
