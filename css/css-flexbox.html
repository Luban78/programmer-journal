🧭 Flexbox a rozložení prvků

Krátký úvod

Flexbox je způsob, jak jednoduše skládat a zarovnávat prvky uvnitř jednoho rodičovského prvku.

Pomocí Flexboxu můžeš prvky umístit vedle sebe, pod sebe, vycentrovat je vodorovně i svisle a nastavit mezi nimi mezery.

Právě Flexbox vyřeší problém z tvého prvního CSS úkolu: jak dostat kartu doprostřed obrazovky.

🧠 Nejdůležitější myšlenka

Flexbox se zapíná na rodičovském prvku.

Rodič potom řídí rozložení svých přímých potomků. 

RODIČ – flex container
┌──────────────────────────────┐
│  POTOMEK  POTOMEK  POTOMEK  │
│  flex item flex item flex item
└──────────────────────────────┘

Rodič se nazývá flex container a jeho přímí potomci se nazývají flex items.

📚 Co se dnes naučíš

  • zapnout Flexbox pomocí display: flex
  • rozlišit rodiče a jeho přímé potomky
  • pochopit hlavní a vedlejší osu
  • měnit směr pomocí flex-direction
  • zarovnávat po hlavní ose pomocí justify-content
  • zarovnávat po vedlejší ose pomocí align-items
  • vytvářet mezery pomocí gap
  • povolit zalamování pomocí flex-wrap
  • vycentrovat kartu uprostřed celé obrazovky

1️⃣ Zapnutí Flexboxu

Flexbox zapneme na rodičovském prvku: 

.rodic {
  display: flex;
}

Tři vnitřní <div> prvky jsou přímí potomci rodiče .rodic.

⚠️ Nejčastější začátečnická chyba

Vlastnost display: flex; se omylem nastaví jednotlivým kartičkám místo jejich rodiči.

Jestli chceš rozkládat tři kartičky, Flexbox nastav jejich společnému obalu.

2️⃣ Hlavní a vedlejší osa

Flexbox pracuje se dvěma směry:

  • hlavní osa – směr, ve kterém se prvky skládají,
  • vedlejší osa – směr kolmý na hlavní osu.

Ve výchozím nastavení jsou prvky v řádku: 

hlavní osa  ─────────────────────►

[ první ] [ druhý ] [ třetí ]

vedlejší osa
      │
      ▼

🧠 Pomůcka

justify-content pracuje po hlavní ose.

align-items pracuje po vedlejší ose.

3️⃣ Flex-direction – směr prvků

Směr určuje vlastnost flex-direction.

Row – vedle sebe

.rodic {
  display: flex;
  flex-direction: row;
}
[ první ] [ druhý ] [ třetí ]

Hodnota row je výchozí, takže ji často nemusíš psát.

Column – pod sebou

.rodic {
  display: flex;
  flex-direction: column;
}
[ první ]
[ druhý ]
[ třetí ]

💡 Co se změnou směru mění

U row vede hlavní osa vodorovně.

U column vede hlavní osa svisle.

4️⃣ Justify-content – hlavní osa

Vlastnost justify-content rozmísťuje prvky po hlavní ose.

Na začátku

justify-content: flex-start;
[1][2][3]

Uprostřed

justify-content: center;
          [1][2][3]

Na konci

justify-content: flex-end;
                     [1][2][3]

Prostor mezi prvky

justify-content: space-between;
[1]          [2]          [3]

Hodnota space-between vloží volný prostor mezi prvky, ale ne před první a za poslední.

5️⃣ Align-items – vedlejší osa

Vlastnost align-items zarovnává prvky po vedlejší ose.

Uprostřed

.rodic {
  display: flex;
  align-items: center;
}
┌──────────────────────────────┐
│                              │
│      [1]  [2]  [3]           │
│                              │
└──────────────────────────────┘

Na začátku nebo na konci

align-items: flex-start;
align-items: flex-end;

⚠️ Proč align-items někdy není vidět

Rodič musí mít ve vedlejším směru nějaký volný prostor.

Jestli je rodič vysoký přesně jako jeho obsah, není kam prvky posunout nahoru, doprostřed nebo dolů.

6️⃣ Gap – mezery mezi prvky

Vlastnost gap nastaví jednotnou mezeru mezi flex prvky. 

.rodic {
  display: flex;
  gap: 15px;
}
[1]   15 px   [2]   15 px   [3]

Výhodou je, že nemusíš každému prvku zvlášť nastavovat margin.

💡 Praktické použití

Pro stejné mezery mezi tlačítky, kartami nebo odkazy používej raději gap.

7️⃣ Flex-wrap – zalamování

Ve výchozím stavu se Flexbox snaží všechny prvky udržet v jednom řádku.

Zalamování povolíš takto: 

.rodic {
  display: flex;
  flex-wrap: wrap;
}

8️⃣ Vycentrování karty uprostřed obrazovky

Toto je řešení, na které jsi čekal od prvního CSS úkolu.

Flexbox nastavíme rodiči, kterým je v tomto případě <body>. 

body {
  min-height: 100vh;

  display: flex;
  justify-content: center;
  align-items: center;
}

Co jednotlivé řádky dělají:

  • min-height: 100vh; zajistí, že body bude vysoké alespoň jako celá obrazovka.
  • display: flex; zapne Flexbox.
  • justify-content: center; vycentruje kartu po hlavní, tedy vodorovné ose.
  • align-items: center; vycentruje kartu po vedlejší, tedy svislé ose. 
┌──────────── obrazovka ────────────┐
│                                   │
│          ┌─────────────┐          │
│          │    karta    │          │
│          └─────────────┘          │
│                                   │
└───────────────────────────────────┘

🧠 Proč potřebujeme 100vh

Bez dostatečné výšky rodiče nemá align-items: center; volný svislý prostor, ve kterém by mohl kartu vycentrovat.

9️⃣ Column a změna os

Když nastavíš: 

flex-direction: column;

hlavní osa se otočí svisle. 

hlavní osa
    │
    ▼

[ první ]
[ druhý ]
[ třetí ]

vedlejší osa ─────────►

V takovém případě:

  • justify-content zarovnává svisle,
  • align-items zarovnává vodorovně.

⚠️ Tady se lidé často spletou

justify-content neznamená vždy vodorovně.

Vždy pracuje po hlavní ose, jejíž směr určuje flex-direction.

💻 Kompletní příklad

Soubor index.html

Soubor style.css

body {
  min-height: 100vh;
  margin: 0;

  display: flex;
  justify-content: center;
  align-items: center;

  background-color: #dfe7f5;
  font-family: Arial, sans-serif;
}

.karta {
  box-sizing: border-box;
  width: 90%;
  max-width: 420px;

  padding: 20px;
  border: 4px solid #334f9c;

  background-color: white;
  color: #252535;
}

h1 {
  color: #334f9c;
  text-align: center;
}

.technologie {
  display: flex;
  justify-content: center;
  flex-wrap: wrap;
  gap: 10px;
}

.technologie span {
  padding: 8px 12px;
  border: 2px solid #334f9c;

  color: #334f9c;
  background-color: #e7ecfa;
}

V příkladu jsou dva samostatné flex kontejnery:

  • <body> centruje celou kartu na obrazovce.
  • .technologie rozkládá jednotlivé štítky vedle sebe.

⚠️ Nejčastější chyby

  • display: flex; je nastaveno potomkům místo jejich společnému rodiči.
  • Zamění se justify-content a align-items.
  • U svislého centrování nemá rodič žádnou větší výšku.
  • Po změně na flex-direction: column; se zapomene, že se otočila hlavní osa.
  • Prvky se na mobilu nevejdou, protože chybí flex-wrap: wrap;.
  • Mezery se složitě nastavují marginem na každém prvku, i když by stačilo použít gap.

📝 Co si zapamatovat

  • Flexbox zapínáme na rodiči pomocí display: flex;.
  • Přímí potomci rodiče se stanou flex items.
  • flex-direction určuje směr hlavní osy.
  • justify-content zarovnává po hlavní ose.
  • align-items zarovnává po vedlejší ose.
  • gap nastavuje mezery mezi prvky.
  • flex-wrap: wrap; povoluje zalomení na další řádek.
  • Pro vycentrování karty uprostřed obrazovky potřebuje rodič dostatečnou výšku, například min-height: 100vh;.

⏭️ Co bude následovat

Nejdřív si tuto lekci v klidu projdi. Zaměř se hlavně na vztah rodiče a potomků.

Potom dostaneš praktický úkol pouze z: display: flex, flex-direction, justify-content, align-items, gap a flex-wrap.

K tomu použiješ pouze dříve zvládnuté barvy, text, box model, rozměry a selektory.
