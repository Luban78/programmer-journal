🎨 Barvy, text a písmo

Krátký úvod

V minulé lekci ses naučil pomocí selektorů vybrat prvky, které chceš upravit.

Teď se naučíš měnit jejich barvu, velikost, tloušťku, zarovnání a další vlastnosti textu.

Všechny dnešní vlastnosti zapisujeme dovnitř CSS pravidla: 

selektor {
  vlastnost: hodnota;
}

🧠 Jak o tom přemýšlet

Selektor odpovídá na otázku: „Co chci upravit?“

CSS vlastnost odpovídá na otázku: „Co na tom chci změnit?“

Hodnota odpovídá na otázku: „Jak přesně to má vypadat?“ 

h1 {
  color: blue;
}

Selektor h1 vybere hlavní nadpis, vlastnost color mění barvu textu a hodnota blue určuje modrou barvu.

📚 Co se dnes naučíš

  • měnit barvu textu a pozadí
  • zapisovat základní barvy názvem a hexadecimálním kódem
  • měnit velikost písma
  • nastavit tučné nebo normální písmo
  • použít kurzívu
  • vybrat rodinu písma
  • zarovnat text vlevo, na střed nebo vpravo
  • text podtrhnout nebo podtržení odstranit
  • upravit výšku řádku pro lepší čitelnost

1️⃣ Barva textu

Barvu textu nastavuje vlastnost color. 

p {
  color: blue;
}

Toto pravidlo nastaví všem odstavcům modrou barvu textu.

Barva zapsaná názvem

h1 {
  color: red;
}

p {
  color: darkgreen;
}

Názvy barev jsou pro začátek přehledné. Nabídka přesných odstínů je ale omezená.

Barva zapsaná hexadecimálním kódem

h1 {
  color: #1faaad;
}

p {
  color: #474147;
}

Hexadecimální barva začíná znakem # a za ním obvykle následuje šest znaků.

Tento zápis umožňuje vybrat mnohem přesnější odstín než běžný název barvy.

💡 Pro začátek

Nemusíš hexadecimální kódy znát zpaměti. Barvu si můžeš vybrat pomocí nabídky barev v editoru a její kód použít v CSS.

2️⃣ Barva pozadí

Barvu pozadí nastavuje vlastnost background-color. 

body {
  background-color: #e9e9ef;
}

Pozadí můžeme nastavit celé stránce, ale také jednomu nadpisu, odstavci nebo jinému prvku. 

h2 {
  background-color: lightblue;
}

🧠 Nezaměňovat

  • color mění barvu textu.
  • background-color mění barvu pozadí za textem nebo prvkem.

3️⃣ Velikost písma

Velikost textu nastavuje vlastnost font-size. 

h1 {
  font-size: 40px;
}

p {
  font-size: 20px;
}

Prozatím budeme používat jednotku px. Jednotky podrobně probereme v samostatné lekci.

Čím vyšší číslo použiješ, tím větší text se zobrazí.

4️⃣ Tloušťka písma

Tloušťku písma nastavuje vlastnost font-weight. 

.dulezite {
  font-weight: bold;
}

Hodnota bold vytvoří tučný text. 

.obycejne {
  font-weight: normal;
}

Hodnota normal vrátí běžnou tloušťku písma.

5️⃣ Kurzíva

Styl písma nastavuje vlastnost font-style. 

.poznamka {
  font-style: italic;
}

Hodnota italic zobrazí text kurzívou. 

.bez-kurzivy {
  font-style: normal;
}

6️⃣ Rodina písma

Druh písma nastavuje vlastnost font-family. 

body {
  font-family: Arial, sans-serif;
}

Prohlížeč se nejdřív pokusí použít písmo Arial. Když ho zařízení nemá, použije některé dostupné bezpatkové písmo ze skupiny sans-serif.

💡 Záložní písmo

Je dobré uvést více možností oddělených čárkou. Poslední možnost bývá obecná rodina, například sans-serif nebo serif.

7️⃣ Zarovnání textu

Zarovnání textu nastavuje vlastnost text-align. 

h1 {
  text-align: center;
}

.text-vlevo {
  text-align: left;
}

.text-vpravo {
  text-align: right;
}
  • left zarovná text vlevo.
  • center zarovná text na střed.
  • right zarovná text vpravo.

⚠️ Pozor

Vlastnost text-align: center; zarovná text uvnitř prvku.

Nevycentruje automaticky celý blok nebo kartu doprostřed obrazovky. Rozložení prvků se naučíš později pomocí Flexboxu.

8️⃣ Podtržení a další ozdoby textu

Ozdobu textu nastavuje vlastnost text-decoration. 

#upozorneni {
  text-decoration: underline;
}

Hodnota underline text podtrhne. 

a {
  text-decoration: none;
}

Hodnota none ozdobu odstraní. Často se používá například pro odstranění výchozího podtržení odkazu.

9️⃣ Výška řádku

Vzdálenost mezi řádky textu nastavuje vlastnost line-height. 

p {
  line-height: 1.6;
}

Vyšší řádkování zlepšuje čitelnost delších odstavců. Hodnota 1.6 znamená, že výška řádku bude přibližně 1,6násobkem velikosti písma.

🔗 Spojení se selektory

Vlastnosti můžeš kombinovat s elementem, třídou i ID, které už znáš z minulé lekce. 

body {
  background-color: #e8e8f2;
  font-family: Arial, sans-serif;
}

h1 {
  color: #34346f;
  font-size: 42px;
  text-align: center;
}

.modry-text {
  color: blue;
  font-weight: bold;
}

#upozorneni {
  color: red;
  text-decoration: underline;
}

⚠️ Nejčastější chyby

  • Chybí středník za hodnotou: color: red.
  • Místo dvojtečky je použito rovnítko: color = red;.
  • U velikosti písma chybí jednotka: font-size: 20;.
  • Barva pozadí se omylem zapisuje do vlastnosti color místo background-color.
  • V CSS se použije český název barvy, který prohlížeč nezná.

📝 Co si zapamatovat

  • color mění barvu textu.
  • background-color mění barvu pozadí.
  • font-size mění velikost textu.
  • font-weight nastavuje tloušťku písma.
  • font-style umožňuje použít kurzívu.
  • font-family vybírá druh písma.
  • text-align zarovnává text uvnitř prvku.
  • text-decoration přidává nebo odstraňuje ozdobu textu.
  • line-height mění vzdálenost mezi řádky.
