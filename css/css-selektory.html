🎯 Selektory: element, třída a ID

Krátký úvod

CSS pravidlo samo o sobě nestačí. Nejdřív musíme prohlížeči říct, který HTML prvek chceme upravit.

K tomu slouží selektor. Selektor stojí před složenými závorkami a vybírá jeden nebo více prvků na stránce. 

selektor {
  vlastnost: hodnota;
}

🧠 Jak o tom přemýšlet

Selektor je jako pokyn:

„Najdi na stránce tento prvek nebo tuto skupinu prvků a použij na ně následující vzhled.“

Dnes se naučíš tři základní způsoby výběru: podle názvu HTML elementu, podle třídy a podle ID.

📚 Co se dnes naučíš

  • co je CSS selektor
  • jak vybrat všechny prvky stejného typu
  • jak pomocí třídy vybrat několik zvolených prvků
  • jak pomocí ID vybrat jeden jedinečný prvek
  • jak se element, třída a ID zapisují v HTML a CSS
  • kdy je vhodné jednotlivé selektory používat

1️⃣ Elementový selektor

Elementový selektor používá přímo název HTML značky.

Následující pravidlo vybere všechny odstavce na stránce: 

p {
  color: #2467c9;
  font-size: 18px;
}

HTML může obsahovat několik odstavců:

Protože CSS vybírá značku p, všechna tři pravidla získají stejnou barvu a velikost písma.

💡 Kdy použít elementový selektor

Použij ho tehdy, když chceš stejný základní vzhled pro všechny prvky jednoho druhu, například všechny odstavce, nadpisy nebo tlačítka.

2️⃣ Třída

Třída slouží pro skupinu prvků, které mají mít společný vzhled. Nemusí přitom jít o stejné HTML značky.

V HTML se třída zapisuje pomocí atributu class:

V CSS píšeme před název třídy tečku: 

.dulezite {
  color: #b71c1c;
  font-weight: bold;
}

Styl dostane první odstavec a tlačítko, protože oba obsahují class="dulezite". Prostřední odstavec tuto třídu nemá, takže se pravidlo na něj nepoužije.

🧠 Důležité pravidlo

Jednu třídu můžeš použít na více prvcích.

Proto je třída nejběžnější způsob, jak v CSS vytvářet opakovaně použitelné styly.

3️⃣ ID

ID označuje jeden konkrétní a jedinečný prvek na stránce.

V HTML se zapisuje atributem id:

V CSS píšeme před název ID znak #: 

#hlavni-zprava {
  color: #7b1fa2;
  text-decoration: underline;
}

Na jedné HTML stránce by se stejné ID nemělo opakovat. Název hlavni-zprava má označovat právě jeden prvek.

💡 Kdy použít ID

ID je vhodné pro skutečně jedinečný prvek nebo tehdy, když ho potřebuješ přesně najít pomocí JavaScriptu či odkazu na část stránky.

Pro běžné stylování opakujících se prvků je většinou praktičtější třída.

🔍 Porovnání všech tří selektorů

p {
  color: gray;
}

.modry-text {
  color: blue;
}

#upozorneni {
  color: red;
}

Jednoduchá pomůcka

  • Element: vyber všechny prvky stejného typu.
  • Třída: vyber zvolenou skupinu prvků.
  • ID: vyber jeden konkrétní prvek.

💻 Kompletní příklad

Soubor index.html

Soubor style.css

p {
  font-size: 18px;
  line-height: 1.6;
}

.zvyrazneny {
  color: #1565c0;
  font-weight: bold;
}

#jedinecny {
  color: #c62828;
  text-decoration: underline;
}

⚠️ Nejčastější chyby

  • V HTML se napíše class=".modry". Tečka ale patří jen do CSS. Správně je class="modry".
  • V HTML se napíše id="#upozorneni". Znak # patří jen do CSS. Správně je id="upozorneni".
  • Stejné ID se použije na více prvcích. Pro opakované použití je určena třída.
  • Název v HTML a CSS se liší například velikostí písmen nebo překlepem.

📝 Co si zapamatovat

  • Elementový selektor zapisujeme názvem značky: p.
  • Třídu zapisujeme v CSS s tečkou: .karta.
  • V HTML se třída zapisuje bez tečky: class="karta".
  • ID zapisujeme v CSS s mřížkou: #hlavni.
  • V HTML se ID zapisuje bez mřížky: id="hlavni".
  • Jednu třídu může používat více prvků, stejné ID má být na stránce jen jednou.

⏭️ Co bude následovat

Tuto lekci si nejdřív v klidu projdi a podívej se na všechny příklady.

Zelený kroužek zatím nezískáváš pouhým přečtením. Po nastudování dostaneš samostatný praktický úkol.

Až ho zvládneš a vysvětlíš rozdíl mezi elementem, třídou a ID, označíme lekci jako opravdu dokončenou.
