📐 Šířka, výška a CSS jednotky

Krátký úvod

V minulé lekci ses naučil, že každý HTML prvek se chová jako krabice.

Teď se naučíš určovat, jak široká nebo vysoká tato krabice bude a jaké jednotky můžeš v CSS používat.

Díky tomu dokážeš vytvořit kartu, která bude mít rozumnou velikost na telefonu i na větší obrazovce.

🧠 Jak o tom přemýšlet

Vlastnost určuje, co měníme. Jednotka říká, podle čeho velikost počítáme. 

.karta {
  width: 300px;
}

width znamená šířka, 300 je hodnota a px je jednotka.

📚 Co se dnes naučíš

  • nastavit šířku pomocí width
  • omezit největší šířku pomocí max-width
  • nastavit výšku a minimální výšku
  • porozumět jednotkám px, %, vw, vh a rem
  • vodorovně vycentrovat blok pomocí automatického marginu
  • pochopit, proč může pevná výška způsobit problém
  • zahrnout padding a border do zadané šířky pomocí box-sizing

1️⃣ Width – šířka

Vlastnost width nastavuje šířku prvku. 

.karta {
  width: 300px;
}

Karta bude široká 300 pixelů.

⚠️ Pozor na pevnou šířku

Pevná šířka může na malém telefonu přesahovat obrazovku.

Proto často nepoužíváme jen pevné width: 420px;, ale kombinujeme procenta a maximální šířku.

2️⃣ Procenta – velikost podle rodiče

Jednotka % nastavuje velikost vzhledem k prostoru rodičovského prvku. 

.karta {
  width: 90%;
}

Karta zabere 90 % dostupné šířky svého rodiče. Na menší obrazovce se proto automaticky zmenší.

🧠 Jednoduchá představa

Pokud má rodič šířku 1 000 px, hodnota 90 % znamená přibližně 900 px.

Pokud má rodič šířku 400 px, stejných 90 % znamená přibližně 360 px.

3️⃣ Max-width – největší povolená šířka

Vlastnost max-width určuje, jak široký smí prvek být nejvýše. 

.karta {
  width: 90%;
  max-width: 420px;
}

Na telefonu bude karta široká přibližně 90 % obrazovky. Na velké obrazovce ale nikdy nepřeroste přes 420 px.

💡 Velmi užitečná kombinace

width: 90%;
max-width: 420px;

Tuto kombinaci budeš často používat u karet, formulářů a panelů.

4️⃣ Vodorovné vycentrování bloku

Když má prvek menší šířku než dostupný prostor, můžeš ho vodorovně vycentrovat automatickým marginem. 

.karta {
  width: 90%;
  max-width: 420px;
  margin: 30px auto;
}

První hodnota 30px nastaví horní a dolní margin.

Hodnota auto rozdělí volný prostor vlevo a vpravo stejně.

🧠 Co už tím dokážeš

Tímto způsobem umíš kartu vycentrovat vodorovně.

Vycentrování zároveň vodorovně i svisle přes celou obrazovku se naučíš později pomocí Flexboxu.

5️⃣ Height – výška

Vlastnost height nastavuje pevnou výšku prvku. 

.panel {
  height: 200px;
}

Panel bude vysoký přesně 200 pixelů.

⚠️ Pevná výška může být nebezpečná

Když se do prvku nevejde obsah, text může přetéct mimo jeho prostor.

U textových karet je proto často lepší výšku vůbec nenastavovat a nechat ji přizpůsobit obsahu.

6️⃣ Min-height – minimální výška

Vlastnost min-height určuje nejmenší povolenou výšku. 

.panel {
  min-height: 200px;
}

Panel bude vysoký nejméně 200 px. Když bude obsah potřebovat více místa, panel se může zvětšit.

Proto je min-height u proměnlivého textu bezpečnější než pevná height.

7️⃣ Jednotka px

Jednotka px označuje pixely. 

h1 {
  font-size: 36px;
}

.karta {
  padding: 20px;
  border: 4px solid blue;
}

Pixely jsou přehledné a vhodné například pro okraje, padding nebo menší pevné rozměry.

8️⃣ Jednotky vw a vh

Jednotka vw znamená procento šířky okna prohlížeče.

Jednotka vh znamená procento výšky okna prohlížeče. 

.sekce {
  width: 80vw;
  min-height: 50vh;
}
  • 100vw odpovídá celé šířce okna,
  • 50vw odpovídá polovině šířky okna,
  • 100vh odpovídá celé výšce okna,
  • 50vh odpovídá polovině výšky okna.

💡 Kde se vh hodí

Hodnota min-height: 100vh; se často používá, když má hlavní část stránky zabírat alespoň celou výšku obrazovky.

9️⃣ Jednotka rem

Jednotka rem se odvozuje od základní velikosti písma celé stránky. 

h1 {
  font-size: 2rem;
}

p {
  font-size: 1.2rem;
}

Pokud je základní velikost písma 16 px, pak přibližně:

  • 1rem = 16 px,
  • 2rem = 32 px,
  • 0.5rem = 8 px.

Výhodou je, že velikosti mohou lépe reagovat na nastavení písma uživatele.

🔟 Box-sizing – co se započítá do šířky

Ve výchozím nastavení se k zadané šířce připočítá padding a border. 

.karta {
  width: 300px;
  padding: 20px;
  border: 5px solid blue;
}

Výsledná karta bude ve skutečnosti širší než 300 px, protože se přidá padding a okraj.

Praktické řešení je: 

.karta {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 5px solid blue;
}

Hodnota border-box zajistí, že zadaná šířka už zahrnuje obsah, padding i border.

💡 Praktické pravidlo

U karet a formulářů je box-sizing: border-box; velmi užitečné, protože se jejich skutečná šířka lépe předvídá.

💻 Kompletní příklad

Soubor index.html

Soubor style.css

body {
  background-color: #dfe7f5;
  font-family: Arial, sans-serif;
}

.karta {
  box-sizing: border-box;

  width: 90%;
  max-width: 420px;
  min-height: 220px;

  padding: 20px;
  border: 4px solid #334f9c;
  margin: 30px auto;

  background-color: white;
  color: #252535;
}

h1 {
  color: #334f9c;
  font-size: 2rem;
  text-align: center;
}

p {
  font-size: 1.1rem;
  line-height: 1.6;
}

🔍 Přehled jednotek

  • px – pevná velikost v pixelech.
  • % – velikost vzhledem k rodičovskému prvku.
  • vw – velikost vzhledem k šířce okna.
  • vh – velikost vzhledem k výšce okna.
  • rem – velikost vzhledem k základnímu písmu stránky.

⚠️ Nejčastější chyby

  • U číselné hodnoty chybí jednotka: width: 300;.
  • Karta má pevnou šířku větší než mobilní obrazovka.
  • Pevná height je příliš malá a obsah přeteče.
  • Očekává se, že width: 90%; bude vždy přesně 90 % obrazovky. Procenta se ale počítají podle rodiče.
  • Prvek je širší, než bylo očekáváno, protože k width se připočítal padding a border.

📝 Co si zapamatovat

  • width nastavuje šířku.
  • max-width omezuje největší šířku.
  • Kombinace width: 90%; a max-width: 420px; je vhodná pro mobilní kartu.
  • margin: 30px auto; vycentruje blok vodorovně.
  • Pevná height může způsobit přetečení obsahu.
  • min-height dovolí prvku podle obsahu růst.
  • box-sizing: border-box; zahrne padding a border do zadané šířky.
