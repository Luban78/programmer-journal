🏁 Malý závěrečný CSS projekt

Krátký úvod

V této části už nepřibude žádná nová CSS vlastnost.

Cílem je spojit dosavadní znalosti do jedné malé responzivní stránky, kterou napíšeš celou od nuly.

Projekt ukáže, zda umíš samostatně přemýšlet o struktuře, vzhledu, rozložení a chování stránky na různých šířkách.

🧠 Jak o projektu přemýšlet

Nezačínej barvami a stíny.

Postupuj v tomto pořadí:

  1. Vytvoř správnou HTML strukturu.
  2. Připoj externí CSS.
  3. Nastav základní text a barvy.
  4. Vytvoř box model jednotlivých částí.
  5. Vyřeš rozměry a rozložení.
  6. Přidej responzivní změnu.
  7. Až nakonec dolaď zaoblení, stíny a detaily.

🎯 Zadání projektu

Vytvoř stránku s názvem: 

Moje cesta programátora

Stránka bude obsahovat:

  • hlavní nadpis a krátký úvod,
  • tři karty: HTML, CSS a JavaScript,
  • u každé karty krátký popis,
  • sekci s dovednostmi nebo technologiemi,
  • jedno výrazné tlačítko,
  • krátkou poznámku nebo upozornění.

✅ Povinné znalosti v projektu

Projekt musí prokázat použití těchto oblastí:

  • externí soubor style.css,
  • elementový selektor, třída a alespoň jedno ID,
  • barvy, písmo a řádkování,
  • padding, border a margin,
  • width, max-width a box-sizing,
  • Flexbox a gap,
  • flex-wrap nebo flex-direction,
  • border-radius a box-shadow,
  • jedna media query s min-width,
  • alespoň tři CSS proměnné v :root.

💡 Nemusíš použít úplně všechno

Nepřidávej vlastnost jen proto, že ji znáš. Použij ji pouze tam, kde má jasný význam.

🎨 CSS proměnné projektu

Připrav si alespoň tři společné hodnoty: 

:root {
  --hlavni-barva: ...;
  --pozadi-stranky: ...;
  --barva-karty: ...;
}

Konkrétní hodnoty si vyber sám.

📱 Responzivní požadavek

Na mobilu budou tři hlavní karty pod sebou.

Od tebou zvoleného breakpointu budou vedle sebe.

Použij pouze jednu media query.

🧠 Breakpoint vybíráš podle vzhledu

Pomalu rozšiřuj náhled a sleduj, kdy mají tři karty dostatek prostoru.

Nevybírej číslo jen proto, že bylo použito v předchozím příkladu.

🧪 Doporučený pracovní postup

  1. Napiš celé HTML bez CSS.
  2. Zkontroluj správné uzavření všech značek.
  3. Nastav základní styl body.
  4. Uprav hlavní obal stránky.
  5. Vytvoř vzhled jedné karty.
  6. Stejnou třídu použij na všechny tři karty.
  7. Zapni Flexbox na jejich rodiči.
  8. Přidej media query.
  9. Dolaď štítky, tlačítko a upozornění.
  10. Nakonec zkontroluj mobilní i široký náhled.

🔍 Kontrolní seznam před odesláním

  • Je v HTML právě jeden <body>?
  • Jsou všechny značky správně uzavřené?
  • Je CSS připojené externím souborem?
  • Neprotéká obsah mimo obrazovku?
  • Jsou karty na mobilu pod sebou?
  • Jsou na širší obrazovce vedle sebe?
  • Je text dobře čitelný?
  • Nejsou stíny nebo barvy zbytečně výrazné?
  • Používáš jednu společnou třídu místo kopírování stejného CSS?
  • Mají CSS proměnné srozumitelné názvy?

⚠️ Co v projektu zatím nepoužívat

  • JavaScript,
  • Grid,
  • position,
  • animace,
  • hover efekty,
  • kód zkopírovaný jako hotové řešení.

Cílem je samostatně upevnit přesně to, co už bylo probrané.

🏆 Jak bude projekt hodnocen

  • HTML struktura: správné a přehledné značky.
  • CSS logika: vhodně zvolené selektory a společné třídy.
  • Box model: rozumné mezery, okraje a rozměry.
  • Flexbox: rodič správně řídí potomky.
  • Responzivita: jedna funkční media query.
  • Vzhled: čitelnost a vyváženost.
  • Porozumění: schopnost vysvětlit vlastní rozhodnutí.

⏭️ Co bude po dokončení

Po úspěšném dokončení tohoto projektu bude CSS kapitola hotová.

Potom přejdeme na JavaScript a tvoje stránky poprvé začnou skutečně reagovat na kliknutí a vstup uživatele.

Později pomocí JavaScriptu vytvoříš také rychlý přístup k právě studovaným lekcím a jeho uložení do localStorage.
