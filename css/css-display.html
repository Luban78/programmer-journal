🧱 Display a chování prvků

Krátký úvod

HTML prvky se na stránce nechovají všechny stejně.

Některé automaticky začínají na novém řádku a zabírají dostupnou šířku. Jiné zůstávají přímo v řádku textu vedle sebe.

Toto chování řídí CSS vlastnost display.

🧠 Jak o tom přemýšlet

Vlastnost display říká prohlížeči:

„Jakým způsobem se má tento prvek umístit mezi ostatní prvky?“

Dnes poznáš čtyři důležité hodnoty:

  • block
  • inline
  • inline-block
  • none

📚 Co se dnes naučíš

  • proč se různé HTML prvky zobrazují jinak
  • jak se chová blokový prvek
  • jak se chová řádkový prvek
  • jak spojit výhody obou pomocí inline-block
  • jak prvek úplně odstranit z rozložení pomocí display: none
  • proč někdy nefunguje nastavená šířka nebo výška
  • jak změnit výchozí chování HTML prvku
  • proč je display důležitý pro budoucí Flexbox

1️⃣ Výchozí chování HTML prvků

Prohlížeč má pro jednotlivé HTML značky nastavenou výchozí hodnotu vlastnosti display.

Například nadpis, odstavec nebo <div> se běžně chovají jako blokové prvky.

Odkaz, <span> nebo <strong> se běžně chovají jako řádkové prvky.

💡 Důležité

Výchozí chování můžeš pomocí CSS změnit. Odkaz můžeš změnit na blok a blok můžeš změnit na řádkový prvek.

2️⃣ Display: block

Blokový prvek obvykle:

  • začne na novém řádku,
  • zabere dostupnou šířku,
  • odsunuje další prvek na nový řádek,
  • umožňuje běžně nastavit šířku a výšku.

┌──────────────────────────────┐
│ druhý blok                   │

Příklad HTML

Příklad CSS

.blok {
  display: block;
  width: 70%;
  padding: 15px;
  margin: 10px;
  background-color: lightblue;
  border: 2px solid darkblue;
}

Každý <div> se zobrazí na vlastním řádku.

🧠 Příklady blokových prvků

Mezi běžné blokové prvky patří například:

<div>, <p>, <h1> až <h6>, <ul> a <section>.

3️⃣ Display: inline

Řádkový prvek obvykle:

  • nezačne automaticky na novém řádku,
  • zabere jen tolik místa, kolik potřebuje jeho obsah,
  • může být vedle jiného řádkového prvku,
  • nerespektuje běžně nastavené width a height.
[první] [druhý] [třetí]

Příklad HTML

Příklad CSS

.stitek {
  display: inline;
  color: darkblue;
  background-color: lightblue;
}

Všechny tři prvky zůstanou v jednom řádku, pokud se tam vejdou.

🧠 Příklady řádkových prvků

Mezi běžné řádkové prvky patří například:

<span>, <a>, <strong> a <em>.

⚠️ Proč někdy nefunguje width

Následující pokus u běžného řádkového prvku nemusí změnit šířku: 

span {
  width: 200px;
}

Důvodem není chyba ve vlastnosti width. Prvek se stále chová jako inline.

4️⃣ Display: inline-block

Hodnota inline-block spojuje výhody řádkového a blokového prvku.

  • prvky mohou stát vedle sebe,
  • zároveň jim můžeš nastavit šířku a výšku,
  • funguje u nich padding, border i margin jako u krabice.

└──────────┘ └──────────┘ └──────────┘

Příklad HTML

Příklad CSS

.tlacitko {
  display: inline-block;

  width: 120px;
  padding: 12px;
  margin: 5px;

  color: white;
  background-color: darkblue;
  text-align: center;
  text-decoration: none;
  border: 2px solid navy;
}

Odkazy zůstávají vedle sebe, ale nyní respektují šířku, padding, border i margin.

💡 Kde se inline-block hodí

Hodí se například pro jednoduchá tlačítka, štítky nebo malé karty, které mají stát vedle sebe.

Pro složitější rozložení se dnes častěji používá Flexbox.

5️⃣ Display: none

Hodnota none prvek úplně odstraní z rozložení stránky. 

.skryty {
  display: none;
}

Skrytý odstavec není vidět a nezůstane po něm ani prázdné místo.

🧠 Důležitý rozdíl

display: none; odstraní prvek i jeho místo v rozložení.

Prvek ale zůstává v HTML a můžeme ho později znovu zobrazit, například pomocí JavaScriptu.

6️⃣ Změna výchozího chování

HTML značka má určité výchozí chování, ale CSS ho může změnit.

Odkaz změněný na blok

a {
  display: block;
  width: 200px;
  padding: 10px;
  margin: 10px;
}

Každý odkaz bude na vlastním řádku a můžeme mu nastavit šířku.

Div změněný na inline-block

.mala-karta {
  display: inline-block;
  width: 120px;
  padding: 10px;
  margin: 5px;
}

Několik <div> prvků pak může stát vedle sebe.

🔍 Přehled hodnot display

  • block – vlastní řádek, běžně respektuje šířku a výšku.
  • inline – zůstává v řádku a zabírá prostor podle obsahu.
  • inline-block – může být vedle ostatních, ale zároveň se chová jako krabice.
  • none – prvek se nezobrazí a nezabírá místo.

⚠️ Nejčastější chyby

  • U prvku inline se nastaví width a očekává se, že bude fungovat.
  • Hodnota se zapíše jako display: inline block;. Správně je display: inline-block;.
  • Prvek zmizí kvůli display: none; a hledá se chyba v HTML.
  • Očekává se, že inline-block automaticky vycentruje prvky. Určuje ale jejich chování, nikoliv samo o sobě zarovnání celé skupiny.
  • Změní se display všem odkazům nebo divům příliš obecným selektorem a ovlivní to i části stránky, které měly zůstat beze změny.

📝 Co si zapamatovat

  • display určuje, jak se prvek chová v rozložení stránky.
  • block obvykle začíná na novém řádku.
  • inline zůstává uvnitř řádku textu.
  • inline běžně nerespektuje nastavenou width a height.
  • inline-block dovolí prvkům stát vedle sebe a zároveň respektovat rozměry.
  • display: none; prvek skryje a odstraní jeho místo z rozložení.
  • CSS může změnit výchozí chování libovolného HTML prvku.

⏭️ Co bude následovat

Nejprve si vyzkoušej změnit stejný prvek mezi hodnotami block, inline a inline-block.

Potom dostaneš praktický úkol pouze z display a ze všech dříve zvládnutých vlastností.

Po zvládnutí úkolu přijde Flexbox. Hodnota display: flex; změní rodičovský prvek na nástroj pro moderní rozložení jeho potomků.
