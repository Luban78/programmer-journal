🎨 Připojení CSS k HTML

Krátký úvod

HTML vytvoří obsah a strukturu stránky. CSS určí, jak bude stránka vypadat.

Aby mohl prohlížeč použít pravidla z CSS souboru, musíme tento soubor správně připojit k HTML dokumentu.

V našich projektech budeme nejčastěji používat samostatný soubor style.css.

🧠 Jak o tom přemýšlet

HTML je kostra stránky a CSS je její vzhled.

Značka <link> mezi nimi vytvoří spojení.

Když je cesta k CSS souboru správná, prohlížeč načte všechna jeho pravidla a použije je na HTML prvky.

📚 Co se dnes naučíš

  • proč oddělujeme HTML a CSS do samostatných souborů
  • kam patří značka <link>
  • k čemu slouží atribut href
  • jak musí být soubory uložené, aby se správně našly
  • jak poznat, že je CSS skutečně připojené

🔗 Doporučený způsob: externí CSS

Nejprve vytvoříme dva samostatné soubory:

projekt/
├── index.html
└── style.css

Do části <head> v souboru index.html vložíme: 

<link rel="stylesheet" href="style.css">

Hodnota stylesheet říká, že připojujeme soubor se styly.

Hodnota style.css určuje cestu k souboru.

💻 Kompletní příklad

Soubor index.html

Soubor style.css

body {
  background-color: #202124;
  color: #f1f1f1;
}

h1 {
  color: #38c8d4;
  text-align: center;
}

💡 Tip

Jestli jsou index.html a style.css ve stejné složce, stačí cesta:

href="style.css"

Jestli je HTML stránka v podsložce, může být potřeba například:

href="../style.css"

⚠️ Nejčastější chyba

HTML stránka se zobrazí, ale styly se vůbec nepoužijí.

Nejčastější příčiny jsou:

  • chybný název souboru
  • chybná cesta v atributu href
  • CSS soubor nebyl uložený
  • soubor má jinou příponu než .css

📝 Co si zapamatovat

  • HTML vytváří obsah, CSS vytváří vzhled.
  • Externí CSS připojujeme v části <head>.
  • Používáme značku <link>.
  • Atribut href obsahuje cestu k CSS souboru.
  • Oddělené soubory udržují projekt přehledný a umožňují použít jeden styl na více HTML stránkách.

💻 Vyzkoušej si

Vytvoř soubory index.html a style.css.

Do HTML vlož nadpis a odstavec. V CSS změň:

  • barvu pozadí stránky
  • barvu hlavního nadpisu
  • zarovnání nadpisu na střed

✅ Očekávaný výsledek

Po otevření HTML stránky se zobrazí změněné pozadí i nadpis. To potvrzuje, že je externí CSS soubor správně připojený.
