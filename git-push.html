📗 Git push

Krátký úvod

Příkaz git push odešle uložené commity z počítače na GitHub.

Teprve po příkazu git push uvidíš své změny i na vzdáleném repozitáři.

🧠 Jak přemýšlet o git push

Git push je jako odeslání uložené hry do cloudu.

Dokud provedeš jen git commit , změny jsou pouze ve tvém počítači.

Po příkazu git push jsou bezpečně uložené i na GitHubu.

📚 Co se dnes naučíš

  • co dělá git push
  • kam se změny odesílají
  • jak odeslat commity
  • jak poznat úspěšný push
  • co znamená upstream branch

💻 Příklady

  • git push

    Odešle všechny commity na GitHub.

  • git push --set-upstream origin moje-vetev

    První push nové větve. Zároveň propojí lokální větev s GitHubem.

  • git status

    Ověří, že je vše synchronizované.

💡 Tip

Před příkazem git push vždy spusť git status.

Ověříš tak, na které větvi pracuješ a zda máš vytvořený commit.

Po prvním push nové větve už obvykle stačí používat pouze git push.

⚠️ Nejčastější chyba

Začátečník zapomene provést git push.

Commit je potom uložený jen v počítači a na GitHubu se změny neobjeví.

📝 Co si zapamatovat

  • git push odešle commity na GitHub.
  • Bez git commit není co odeslat.
  • První push nové větve může vyžadovat parametr --set-upstream.
  • Po úspěšném push jsou lokální větev a GitHub synchronizované.
