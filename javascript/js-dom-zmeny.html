🪄 Změna textu, tříd a obsahu

Krátký úvod

Po výběru prvku a zachycení události může JavaScript stránku změnit.

Může upravit text, přidat CSS třídu, skrýt prvek nebo vytvořit úplně nový obsah.

🧠 Doporučený postup


1. HTML vytvoří prvek
2. CSS připraví možné vzhledy
3. JavaScript přepíná stav

JavaScript nemá zbytečně obsahovat celý vzhled. Vzhled patří především do CSS tříd.

📚 Co se dnes naučíš

  • měnit text pomocí textContent
  • přidávat a odebírat třídy
  • přepínat stav pomocí classList.toggle()
  • používat atribut hidden
  • vytvářet nový prvek pomocí createElement()
  • vložit prvek pomocí append()
  • bezpečně pracovat s innerHTML

1️⃣ Změna textu


const nadpis = document.querySelector("#nadpis");

nadpis.textContent = "Nový nadpis";

2️⃣ Změna textu po kliknutí


const stav = document.querySelector("#stav");
const tlacitko = document.querySelector("#dokoncit");

tlacitko.addEventListener("click", () => {
  stav.textContent = "Lekce je dokončená.";
});

3️⃣ Přidání CSS třídy


stav.classList.add("je-hotovo");


.je-hotovo {
  color: darkgreen;
  font-weight: bold;
}

JavaScript mění stav a CSS určuje vzhled tohoto stavu.

4️⃣ Odebrání třídy


stav.classList.remove("je-hotovo");

5️⃣ Toggle – přepnutí


tlacitko.addEventListener("click", () => {
  document.body.classList.toggle("tmave-tema");
});

Pokud třída neexistuje, přidá se. Pokud už existuje, odebere se.

6️⃣ Zjištění, zda třída existuje


const jeTmave = document.body.classList.contains("tmave-tema");

console.log(jeTmave);

7️⃣ Skrytí prvku


const napoveda = document.querySelector("#napoveda");

napoveda.hidden = true;
napoveda.hidden = false;

Boolean vlastnost hidden určuje, zda je prvek skrytý.

8️⃣ Vytvoření nového prvku


const novaPolozka = document.createElement("li");

novaPolozka.textContent = "JavaScript";

Prvek zatím existuje pouze v JavaScriptu a ještě není vložený do stránky.

9️⃣ Vložení do stránky


const seznam = document.querySelector("#seznam");
const novaPolozka = document.createElement("li");

novaPolozka.textContent = "JavaScript";

seznam.append(novaPolozka);

🔟 Odstranění prvku


novaPolozka.remove();

1️⃣1️⃣ InnerHTML


const panel = document.querySelector("#panel");

panel.innerHTML = "<strong>Hotovo</strong>";

⚠️ Pozor na obsah od uživatele

Nevkládej pomocí innerHTML neověřený text od uživatele.

Pro obyčejný text používej raději textContent.

💻 Kompletní příklad – přepínač tématu

index.html

style.css


body {
  background-color: white;
  color: #222222;
}

body.tmave-tema {
  background-color: #17171d;
  color: #f3f3f7;
}

script.js


const tlacitko = document.querySelector("#tema");

tlacitko.addEventListener("click", () => {
  document.body.classList.toggle("tmave-tema");
});

📝 Co si zapamatovat

  • textContent bezpečně mění text.
  • classList.add() přidává třídu.
  • classList.remove() třídu odstraňuje.
  • classList.toggle() přepíná stav.
  • createElement() vytvoří nový prvek.
  • append() vloží prvek do stránky.
  • Pro text od uživatele používej raději textContent.
