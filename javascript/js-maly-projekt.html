🏁 Malý závěrečný JavaScript projekt

Krátký úvod

V závěrečném projektu spojíš proměnné, podmínky, funkce, DOM, události, formuláře, pole a localStorage.

Nebudeš dostávat hotové řešení. Projekt rozdělíme na malé etapy a každou společně zkontrolujeme.

🧠 Projekt: Studijní plán

Vytvoříš malou aplikaci, do které přidáš témata k nastudování.

Každé téma půjde označit jako dokončené, odstranit a zachovat po obnovení stránky.

📚 Co projekt procvičí

  • HTML formulář a seznam,
  • CSS stavy dokončené položky,
  • proměnné a funkce,
  • událost submit,
  • čtení hodnoty inputu,
  • pole objektů,
  • vytváření prvků v DOM,
  • podmínky,
  • metody find() a filter(),
  • ukládání do localStorage,
  • výpočet a zobrazení postupu.

1️⃣ Datový model položky

Každé téma bude objekt:


{
  id: 1722512345678,
  nazev: "DOM a výběr prvků",
  jeHotovo: false,
}
  • id jednoznačně rozliší položku,
  • nazev obsahuje text od uživatele,
  • jeHotovo ukládá stav.

2️⃣ Povinné funkce aplikace

  1. Přidat nové téma z formuláře.
  2. Zakázat uložení prázdného tématu.
  3. Zobrazit všechny položky.
  4. Přepnout stav hotovo / rozpracováno.
  5. Odstranit vybranou položku.
  6. Zobrazit počet dokončených položek.
  7. Uložit seznam do localStorage.
  8. Po načtení obnovit uložený seznam.

3️⃣ Doporučené HTML části

  • hlavní nadpis,
  • formulář s inputem a tlačítkem,
  • místo pro chybovou zprávu,
  • seznam témat,
  • text s postupem.

4️⃣ Doporučené funkce v JavaScriptu


nactiTemata()
ulozTemata()
zobrazTemata()
pridejTema()
prepniTema()
smazTema()
aktualizujPostup()

Názvy jsou doporučení. Důležité je, aby každá funkce měla jeden jasný úkol.

5️⃣ Pracovní etapy

  1. Etapa 1: pouze správné HTML.
  2. Etapa 2: CSS vzhled a responzivita.
  3. Etapa 3: přidání jednoho tématu.
  4. Etapa 4: pole témat a vykreslování.
  5. Etapa 5: přepínání dokončení.
  6. Etapa 6: mazání.
  7. Etapa 7: localStorage.
  8. Etapa 8: postup a finální kontrola.

💡 Budeme pokračovat naším stylem

Nedostaneš všechny etapy jako jeden obrovský úkol.

Vždy vyřešíš jen jednu konkrétní část, pošleš celý aktuální soubor a opravíme případně jeden problém najednou.

6️⃣ Kontrolní seznam

  • Jsou všechny HTML značky správně uzavřené?
  • Je JavaScript v samostatném souboru?
  • Má každá funkce srozumitelný název?
  • Není stejný kód zbytečně zkopírovaný vícekrát?
  • Je prázdný vstup odmítnutý?
  • Vykresluje se UI podle pole dat?
  • Ukládá se po každé změně?
  • Obnoví se data po načtení?
  • Funguje aplikace i bez uložených dat?
  • Je ovládání použitelné na mobilu?

⚠️ Co zatím do projektu nepřidávat

  • API nebo databázi,
  • přihlašování,
  • složitou animaci,
  • knihovny a frameworky,
  • funkce, kterým zatím nerozumíš.

🏆 Dokončení kapitoly

Až bude projekt fungovat a dokážeš vysvětlit jeho hlavní části, budeš mít hotové pevné základy JavaScriptu.

Potom budeme pokračovat složitější prací s DOM, moduly, asynchronním kódem, API a vlastními aplikacemi.

📝 Co si zapamatovat

  • Velký projekt se skládá z malých ověřitelných etap.
  • Data mají být oddělená od vykreslení stránky.
  • UI se má znovu vytvořit z aktuálního pole dat.
  • Po změně dat je potřeba uložit nový stav.
  • Čitelný kód je důležitější než nejkratší zápis.
