🔍 DOM a výběr prvků stránky

Krátký úvod

DOM je JavaScriptový obraz aktuální HTML stránky. Díky němu může JavaScript vyhledat konkrétní prvek a pracovat s ním.

🧠 HTML se změní na strom prvků


document
└── html
    └── body
        ├── h1
        ├── p
        └── button

JavaScript nejdřív prvek vybere. Teprve potom může číst nebo měnit jeho vlastnosti.

📚 Co se dnes naučíš

  • co je DOM
  • vybrat prvek pomocí querySelector()
  • vybrat více prvků pomocí querySelectorAll()
  • používat stejné selektory jako v CSS
  • přečíst text prvku
  • poznat hodnotu null
  • bezpečně ověřit, že prvek existuje

1️⃣ Příklad HTML

2️⃣ Výběr podle elementu


const nadpis = document.querySelector("h1");

console.log(nadpis);

3️⃣ Výběr podle třídy


const tlacitko = document.querySelector(".tlacitko");

console.log(tlacitko);

4️⃣ Výběr podle ID


const hlavniNadpis = document.querySelector("#hlavni-nadpis");

console.log(hlavniNadpis);

Do querySelector() zapisuješ CSS selektor jako text.

5️⃣ Výběr prvního odpovídajícího prvku


const prvniLekce = document.querySelector(".lekce");

console.log(prvniLekce);

querySelector() vrátí pouze první odpovídající prvek.

6️⃣ Výběr všech prvků


const vsechnyLekce = document.querySelectorAll(".lekce");

console.log(vsechnyLekce);
console.log(vsechnyLekce.length);

Výsledkem je seznam podobný poli, který obsahuje všechny odpovídající prvky.

7️⃣ Čtení textu


const nadpis = document.querySelector("h1");

console.log(nadpis.textContent);

Vlastnost textContent obsahuje text uvnitř prvku.

8️⃣ Když prvek neexistuje


const neexistujiciPrvek = document.querySelector(".neexistuje");

console.log(neexistujiciPrvek);

Výsledkem bude null.

⚠️ Práce s null vyvolá chybu


const prvek = document.querySelector(".neexistuje");

console.log(prvek.textContent);

JavaScript nemůže číst text prvku, který nebyl nalezen.

9️⃣ Bezpečná kontrola


const prvek = document.querySelector(".popis");

if (prvek) {
  console.log(prvek.textContent);
}

Kód uvnitř podmínky se spustí pouze tehdy, když byl prvek nalezen.

🔟 Přesnější selektor


const nadpisKarty = document.querySelector(".karta h2");
const tlacitkoVMenu = document.querySelector(".menu button");

Můžeš používat stejné složené selektory, jaké už znáš z CSS.

💻 Kompletní příklad

index.html

script.js


const nadpis = document.querySelector("#nadpis");
const popis = document.querySelector(".popis");
const lekce = document.querySelectorAll(".lekce");

console.log(nadpis.textContent);
console.log(popis.textContent);
console.log(`Počet lekcí: ${lekce.length}`);

📝 Co si zapamatovat

  • DOM zpřístupňuje HTML prvky JavaScriptu.
  • querySelector() vrátí první nalezený prvek.
  • querySelectorAll() vrátí všechny odpovídající prvky.
  • Selektor zapisujeme jako text.
  • textContent čte text prvku.
  • Nenalezený prvek má hodnotu null.
