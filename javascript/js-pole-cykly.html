🔁 Pole, objekty a cykly

Krátký úvod

Pole uchovává více hodnot v jednom uspořádaném seznamu. Objekt seskupuje související vlastnosti pod jeden celek. Cyklus opakuje stejnou práci pro více položek.

🧠 Proč to potřebujeme

Záložky Programmer Journalu nebudou jedna samostatná proměnná. Budou seznamem několika lekcí.

Každá lekce může mít název, adresu a stav. Právě proto potřebujeme pole objektů.

📚 Co se dnes naučíš

  • vytvořit pole
  • přečíst položku podle indexu
  • zjistit délku pole
  • přidat a odebrat položku
  • projít pole pomocí for...of a forEach()
  • vytvořit objekt
  • přečíst vlastnost objektu
  • vytvořit pole objektů
  • vyhledat položku pomocí find()
  • vytvořit nové pole pomocí filter()

1️⃣ Pole


const technologie = ["HTML", "CSS", "JavaScript"];

console.log(technologie);

2️⃣ Index začíná nulou


console.log(technologie[0]);
console.log(technologie[1]);
console.log(technologie[2]);


index:    0        1          2
hodnota: HTML     CSS        JavaScript

3️⃣ Délka pole

console.log(technologie.length);

4️⃣ Přidání položky


technologie.push("Git");

console.log(technologie);

5️⃣ Odebrání poslední položky


const odebranaPolozka = technologie.pop();

console.log(odebranaPolozka);

6️⃣ For...of


for (const technologieNazev of technologie) {
  console.log(technologieNazev);
}

Cyklus se spustí jednou pro každou položku pole.

7️⃣ ForEach


technologie.forEach((technologieNazev) => {
  console.log(technologieNazev);
});

Metoda forEach() přijme funkci, kterou zavolá pro každou položku.

8️⃣ Objekt


const lekce = {
  nazev: "Flexbox",
  kapitola: "CSS",
  jeHotova: true,
};

Objekt obsahuje dvojice vlastnost: hodnota.

9️⃣ Čtení vlastností


console.log(lekce.nazev);
console.log(lekce.kapitola);
console.log(lekce.jeHotova);

🔟 Změna vlastnosti


lekce.jeHotova = false;

Proměnná je vytvořená pomocí const, ale obsah objektu můžeme upravit. Nemůžeme pouze přiřadit úplně nový objekt do stejné proměnné.

1️⃣1️⃣ Pole objektů


const lekce = [
  {
    nazev: "HTML struktura",
    kapitola: "HTML",
    jeHotova: true,
  },
  {
    nazev: "Flexbox",
    kapitola: "CSS",
    jeHotova: true,
  },
  {
    nazev: "Proměnné",
    kapitola: "JavaScript",
    jeHotova: false,
  },
];

1️⃣2️⃣ Průchod polem objektů


lekce.forEach((lekcePolozka) => {
  console.log(`${lekcePolozka.kapitola}: ${lekcePolozka.nazev}`);
});

1️⃣3️⃣ Find – nalezení jedné položky


const nalezenaLekce = lekce.find((lekcePolozka) => {
  return lekcePolozka.nazev === "Flexbox";
});

console.log(nalezenaLekce);

1️⃣4️⃣ Filter – vybrání více položek


const hotoveLekce = lekce.filter((lekcePolozka) => {
  return lekcePolozka.jeHotova;
});

console.log(hotoveLekce);

1️⃣5️⃣ Vykreslení seznamu do HTML


const seznam = document.querySelector("#seznam-lekci");

lekce.forEach((lekcePolozka) => {
  const polozka = document.createElement("li");

  polozka.textContent =
    `${lekcePolozka.kapitola}: ${lekcePolozka.nazev}`;

  seznam.append(polozka);
});

⚠️ Index mimo pole

console.log(technologie[99]);

Výsledkem bude undefined, protože na tomto indexu žádná položka není.

📝 Co si zapamatovat

  • Pole uchovává uspořádaný seznam hodnot.
  • První položka má index 0.
  • length vrací počet položek.
  • push() přidá položku na konec.
  • Objekt seskupuje vlastnosti jednoho celku.
  • Pole objektů je vhodné pro seznam lekcí nebo záložek.
  • find() hledá jednu položku.
  • filter() vytváří výběr více položek.
