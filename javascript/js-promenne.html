📦 Proměnné const a let

Krátký úvod

Program často potřebuje hodnotu pojmenovat a později ji znovu použít. K tomu slouží proměnné.

Proměnnou si můžeš představit jako pojmenovanou krabičku, ve které je uložená určitá hodnota.

🧠 Jak o tom přemýšlet


krabička: jmeno
hodnota:  Lubomír

krabička: pocetLekci
hodnota:  12

Místo opakování hodnoty používáš její srozumitelný název.

📚 Co se dnes naučíš

  • vytvořit proměnnou pomocí const
  • vytvořit měnitelnou proměnnou pomocí let
  • proměnnou přečíst a vypsat
  • změnit hodnotu proměnné
  • správně pojmenovávat proměnné
  • pochopit rozdíl mezi deklarací a přiřazením

1️⃣ Const – hodnota, kterou nepřepisujeme


const jmeno = "Lubomír";
console.log(jmeno);

Slovo const vytvoří proměnnou.

jmeno je její název a "Lubomír" je uložená hodnota.

2️⃣ Let – hodnota, kterou později měníme


let pocetLekci = 1;

console.log(pocetLekci);

pocetLekci = 2;

console.log(pocetLekci);

Proměnnou vytvořenou pomocí let můžeme později přepsat.

3️⃣ Const nelze znovu přiřadit

⚠️ Toto vyvolá chybu


const kapitola = "CSS";
kapitola = "JavaScript";

Když víš, že nebudeš přiřazovat novou hodnotu, použij const.

4️⃣ Preferuj const

Praktické pravidlo:

  • začni pomocí const,
  • let použij, pouze když hodnotu opravdu potřebuješ měnit.

5️⃣ Srozumitelné názvy


const vek = 47;
const nazevProjektu = "Programmer Journal";
const jeLekceHotova = true;

V JavaScriptu se často používá zápis camelCase. První slovo začíná malým písmenem a další slova velkým: 

nazevProjektu
pocetDokoncenychLekci
jeUzivatelPrihlasen

⚠️ Nevhodné názvy


const x = "Programmer Journal";
const a = 12;

Kód sice funguje, ale z názvu nepoznáš význam uložené hodnoty.

6️⃣ Co název nesmí obsahovat

  • mezery,
  • pomlčku uprostřed názvu,
  • název nesmí začít číslem,
  • nepoužívej vyhrazená slova jako const nebo if.

const mojeJmeno = "Lubomír";
const lekce2 = "Proměnné";

7️⃣ Výpočet pomocí proměnných


const hotoveLekce = 8;
const vsechnyLekce = 12;
const zbyva = vsechnyLekce - hotoveLekce;

console.log(zbyva);

Výsledkem bude číslo 4.

8️⃣ Spojení textu a proměnné


const jmeno = "Lubomír";

console.log("Ahoj " + jmeno);

Operátor + zde spojuje dva texty.

9️⃣ Template literal


const jmeno = "Lubomír";
const lekce = "JavaScript";

console.log(`Ahoj ${jmeno}, právě studuješ ${lekce}.`);

Text je mezi zpětnými apostrofy ` a proměnnou vložíš pomocí ${nazev}.

💻 Kompletní příklad


const jmeno = "Lubomír";
const nazevKnihy = "Programmer Journal";

let hotoveLekce = 8;
hotoveLekce = hotoveLekce + 1;

console.log(`Uživatel: ${jmeno}`);
console.log(`Projekt: ${nazevKnihy}`);
console.log(`Dokončené lekce: ${hotoveLekce}`);

📝 Co si zapamatovat

  • const používáme pro hodnotu, kterou nepřepisujeme.
  • let používáme pro hodnotu, kterou budeme měnit.
  • Název má vysvětlovat význam hodnoty.
  • V JavaScriptu používáme často camelCase.
  • Proměnnou můžeme použít ve výpočtu nebo textu.
  • Template literal usnadňuje skládání textu a hodnot.
