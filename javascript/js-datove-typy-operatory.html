🔢 Datové typy a základní operátory

Krátký úvod

Proměnná může obsahovat různé druhy hodnot. JavaScript se podle typu hodnoty rozhoduje, jak s ní bude pracovat.

🧠 Stejný znak může dělat něco jiného


console.log(2 + 3);
console.log("2" + "3");

První výsledek je číslo 5. Druhý výsledek je text "23".

📚 Co se dnes naučíš

  • string, number a boolean
  • hodnoty null a undefined
  • zjistit typ pomocí typeof
  • základní matematické operátory
  • porovnávací operátory
  • přísné porovnání ===
  • logické operátory

1️⃣ String – text


const jmeno = "Lubomír";
const projekt = 'Programmer Journal';
const zprava = `Právě studuji ${projekt}.`;

String zapisujeme do uvozovek nebo zpětných apostrofů.

2️⃣ Number – číslo


const vek = 47;
const cena = 129.90;
const teplota = -5;

JavaScript používá jeden základní typ number pro celá i desetinná čísla.

⚠️ Desetinná tečka

V kódu se desetinné číslo zapisuje s tečkou: 

const cena = 129.90;

Čárka by měla jiný význam.

3️⃣ Boolean – ano nebo ne


const jeLekceHotova = true;
const jeUzivatelOdhlasen = false;

Boolean má pouze dvě hodnoty: true a false.

4️⃣ Undefined a null


let vybranaLekce;
console.log(vybranaLekce);

const posledniChyba = null;
  • undefined obvykle znamená, že hodnota zatím nebyla přiřazena.
  • null používáme, když úmyslně říkáme „žádná hodnota“.

5️⃣ Zjištění typu


console.log(typeof "Ahoj");
console.log(typeof 47);
console.log(typeof true);
console.log(typeof undefined);

Operátor typeof vrací název typu jako text.

6️⃣ Matematické operátory


console.log(10 + 5);
console.log(10 - 5);
console.log(10 * 5);
console.log(10 / 5);
console.log(10 % 3);
console.log(5 ** 2);
  • + sčítání,
  • - odčítání,
  • * násobení,
  • / dělení,
  • % zbytek po dělení,
  • ** mocnina.

7️⃣ Změna číselné hodnoty


let skore = 10;

skore = skore + 1;
skore += 5;
skore++;

console.log(skore);

Všechny tři zápisy mění původní hodnotu proměnné.

8️⃣ Porovnání


console.log(5 > 3);
console.log(5 < 3);
console.log(5 >= 5);
console.log(5 === 5);
console.log(5 !== 3);

Výsledkem porovnání je vždy boolean: true nebo false.

9️⃣ Přísné porovnání


console.log(5 === 5);
console.log(5 === "5");

Druhé porovnání vrátí false, protože číslo a text jsou různé typy.

💡 Praktické pravidlo

Používej === a !== místo volnějších variant == a !=.

🔟 Logické operátory


const jePrihlasen = true;
const maOpravneni = true;

console.log(jePrihlasen && maOpravneni);
console.log(jePrihlasen || maOpravneni);
console.log(!jePrihlasen);
  • && znamená „a zároveň“,
  • || znamená „nebo“,
  • ! obrací boolean hodnotu.

📝 Co si zapamatovat

  • String je text.
  • Number je číslo.
  • Boolean je true nebo false.
  • typeof zjistí typ hodnoty.
  • Operátor + může sčítat čísla nebo spojovat text.
  • Porovnání vrací boolean.
  • Pro rovnost používej přísné ===.
