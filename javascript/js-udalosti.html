👆 Události a addEventListener

Krátký úvod

Událost je něco, co se stalo: uživatel klikl, napsal text, odeslal formulář nebo stiskl klávesu.

JavaScript může na událost čekat a spustit připravenou funkci.

🧠 Tři části události


1. vyber prvek
2. poslouchej událost
3. spusť funkci

📚 Co se dnes naučíš

  • použít addEventListener()
  • reagovat na kliknutí
  • předat funkci bez okamžitého spuštění
  • použít objekt události
  • reagovat na input a submit
  • zastavit výchozí chování pomocí preventDefault()

1️⃣ Kliknutí na tlačítko


const tlacitko = document.querySelector("#pozdrav");

tlacitko.addEventListener("click", () => {
  console.log("Na tlačítko bylo kliknuto.");
});

První argument je název události. Druhý argument je funkce, která se spustí po události.

2️⃣ Pojmenovaná funkce


const tlacitko = document.querySelector("#pozdrav");

function pozdravUzivatele() {
  console.log("Ahoj Lubo!");
}

tlacitko.addEventListener("click", pozdravUzivatele);

⚠️ Nepřidávej závorky při předávání funkce

tlacitko.addEventListener("click", pozdravUzivatele());

Tento zápis funkci spustí okamžitě a do posluchače předá její výsledek. 

tlacitko.addEventListener("click", pozdravUzivatele);

3️⃣ Objekt události


tlacitko.addEventListener("click", (event) => {
  console.log(event);
  console.log(event.target);
});

Objekt event obsahuje informace o konkrétní události.

4️⃣ Událost input


const vstup = document.querySelector("#jmeno");

vstup.addEventListener("input", () => {
  console.log(vstup.value);
});

Událost input se spouští při každé změně hodnoty pole.

5️⃣ Událost change


vstup.addEventListener("change", () => {
  console.log("Hodnota byla potvrzena.");
});

U textového pole se change obvykle spustí po potvrzení změny nebo opuštění pole.

6️⃣ Odeslání formuláře


const formular = document.querySelector("#formular");

formular.addEventListener("submit", (event) => {
  event.preventDefault();

  console.log("Formulář zpracoval JavaScript.");
});

Prohlížeč by formulář běžně odeslal a obnovil stránku. Metoda preventDefault() toto výchozí chování zastaví.

7️⃣ Více tlačítek


const tlacitka = document.querySelectorAll(".volba");

tlacitka.forEach((tlacitko) => {
  tlacitko.addEventListener("click", () => {
    console.log(tlacitko.textContent);
  });
});

Každému nalezenému tlačítku přidáme vlastní posluchač.

8️⃣ Událost se spustí až později

Při načtení stránky JavaScript pouze nastaví posluchač. Funkce uvnitř se spustí až ve chvíli, kdy uživatel opravdu klikne nebo provede jinou událost.

💡 Názvy událostí jsou text


"click"
"input"
"change"
"submit"
"keydown"

💻 Kompletní příklad


const tlacitko = document.querySelector("#pocitadlo");

let pocetKliknuti = 0;

tlacitko.addEventListener("click", () => {
  pocetKliknuti += 1;
  console.log(`Počet kliknutí: ${pocetKliknuti}`);
});

📝 Co si zapamatovat

  • addEventListener() čeká na událost.
  • Funkci předáváme bez závorek.
  • event obsahuje informace o události.
  • input reaguje na změnu pole.
  • submit patří formuláři.
  • preventDefault() zastaví výchozí chování.
