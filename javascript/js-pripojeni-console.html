🔌 Připojení JavaScriptu a console.log

Krátký úvod

HTML vytváří obsah stránky a CSS určuje její vzhled. JavaScript přidává příkazy, rozhodování a reakce na uživatele.

V první lekci připojíš samostatný soubor script.js a ověříš jeho spuštění pomocí console.log().

🧠 Jak o tom přemýšlet

Soubor HTML řekne prohlížeči: „Načti také tento JavaScriptový soubor.“

Prohlížeč potom přečte příkazy v souboru shora dolů a postupně je vykoná.

📚 Co se dnes naučíš

  • vytvořit soubor script.js
  • připojit ho pomocí značky <script>
  • vypsat zprávu pomocí console.log()
  • poznat rozdíl mezi textem a příkazem
  • psát jednoduché komentáře
  • pochopit, proč umísťujeme script na konec body

1️⃣ Připojení externího souboru

Atribut src obsahuje cestu k JavaScriptovému souboru.

Když jsou index.html a script.js ve stejné složce, stačí napsat:

2️⃣ První příkaz

Do souboru script.js napiš:

console.log("JavaScript funguje!");

Funkce console.log() vypíše hodnotu do konzole prohlížeče.

💡 Proč je console.log užitečný

Umožní ti rychle ověřit, zda se určitá část programu spustila a jakou hodnotu právě obsahuje proměnná.

3️⃣ Text musí být v uvozovkách

console.log("Ahoj Lubo");
console.log('Učím se JavaScript');

Textová hodnota se v JavaScriptu nazývá string a zapisuje se do uvozovek.

⚠️ Nejčastější chyba

console.log(JavaScript funguje);

Bez uvozovek JavaScript nepovažuje obsah za text. Hledal by proměnné s názvy JavaScript a funguje.

4️⃣ Více příkazů


console.log("První zpráva");
console.log("Druhá zpráva");
console.log(2 + 3);

Příkazy se vykonají shora dolů. Poslední příkaz nevypíše text, ale výsledek výpočtu: 5.

5️⃣ Středník

console.log("Ahoj");

JavaScript často funguje i bez středníku, ale v naší učebnici ho budeme na konci jednoduchých příkazů používat.

6️⃣ Komentáře


// Jednořádkový komentář

console.log("Tento příkaz se spustí");

/*
  Víceřádkový komentář
  může mít několik řádků.
*/

Komentář je poznámka pro člověka. JavaScript ho nevykonává.

7️⃣ Proč je script na konci body

Prohlížeč nejdřív vytvoří HTML obsah a potom spustí JavaScript. To se nám bude hodit, až JavaScript začne vyhledávat a měnit prvky stránky.

💡 Druhá možnost: defer

Atribut defer dovoluje vložit script také do <head>.

V Programmer Journalu zatím zůstaneme u přehledného zápisu těsně před </body>.

💻 Kompletní příklad

index.html

script.js


console.log("Programmer Journal");
console.log("JavaScript je správně připojený.");
console.log(5 * 5);

📝 Co si zapamatovat

  • JavaScript píšeme do souboru script.js.
  • Soubor připojujeme značkou <script src="...">.
  • console.log() vypisuje hodnoty do konzole.
  • Text musí být v uvozovkách.
  • Příkazy se vykonávají shora dolů.
  • Komentáře se nespouštějí.

⏭️ Co bude následovat

V dalším úkolu vytvoříš jednoduchou HTML stránku, připojíš vlastní script a vypíšeš několik zpráv a výpočtů.
