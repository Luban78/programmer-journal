⌨️ Vstup od uživatele a formuláře

Krátký úvod

Formulář umožní uživateli zadat data. JavaScript je může přečíst, zkontrolovat a zobrazit výsledek bez obnovení celé stránky.

🧠 Tok dat ve formuláři


uživatel zadá hodnotu
        ↓
JavaScript přečte .value
        ↓
hodnotu zkontroluje
        ↓
zobrazí výsledek nebo chybu

📚 Co se dnes naučíš

  • přečíst hodnotu inputu
  • odstranit mezery pomocí trim()
  • zpracovat odeslání formuláře
  • použít preventDefault()
  • zkontrolovat prázdnou hodnotu
  • převést text na číslo
  • vyčistit formulář
  • zobrazit uživateli zpětnou vazbu

1️⃣ Čtení hodnoty inputu


const vstup = document.querySelector("#jmeno");
const tlacitko = document.querySelector("#zobrazit");

tlacitko.addEventListener("click", () => {
  console.log(vstup.value);
});

Vlastnost value obsahuje aktuální hodnotu formulářového pole.

2️⃣ Odstranění přebytečných mezer


const jmeno = vstup.value.trim();

Metoda trim() odstraní mezery na začátku a na konci textu.

3️⃣ Odeslání formuláře


const formular = document.querySelector("#formular");
const temaInput = document.querySelector("#tema");
const vysledek = document.querySelector("#vysledek");

formular.addEventListener("submit", (event) => {
  event.preventDefault();

  const tema = temaInput.value.trim();

  vysledek.textContent = tema;
});

4️⃣ Kontrola prázdného vstupu


if (tema === "") {
  vysledek.textContent = "Nejdřív napiš téma.";
  return;
}

return ukončí funkci, takže se další kód při chybě nespustí.

5️⃣ Změna vzhledu chybové zprávy


if (tema === "") {
  vysledek.textContent = "Nejdřív napiš téma.";
  vysledek.classList.add("chyba-formulare");
  return;
}

vysledek.classList.remove("chyba-formulare");

6️⃣ Převod textu na číslo


const pocetInput = document.querySelector("#pocet");
const pocet = Number(pocetInput.value);

console.log(pocet + 1);

Hodnota inputu je text i tehdy, když má pole typ number.

⚠️ Bez převodu se text spojí


const hodnota = "5";

console.log(hodnota + 1);

Výsledkem bude text "51".

7️⃣ Kontrola čísla


const pocet = Number(pocetInput.value);

if (Number.isNaN(pocet)) {
  console.log("Hodnota není platné číslo.");
}

8️⃣ Vyčištění pole


temaInput.value = "";

Po úspěšném zpracování můžeš input připravit pro další hodnotu.

9️⃣ Reset celého formuláře

formular.reset();

💻 Kompletní příklad


const formular = document.querySelector("#studium-formular");
const input = document.querySelector("#studium-tema");
const zprava = document.querySelector("#zprava");

formular.addEventListener("submit", (event) => {
  event.preventDefault();

  const tema = input.value.trim();

  if (tema === "") {
    zprava.textContent = "Napiš nejdřív téma studia.";
    zprava.classList.add("chyba-formulare");
    return;
  }

  zprava.classList.remove("chyba-formulare");
  zprava.textContent = `Dnes studuješ: ${tema}`;

  formular.reset();
});

📝 Co si zapamatovat

  • Hodnotu pole čteme přes value.
  • trim() odstraní krajní mezery.
  • Formulář poslouchá událost submit.
  • preventDefault() zabrání obnovení stránky.
  • Číselný vstup převádíme pomocí Number().
  • reset() vyčistí celý formulář.
