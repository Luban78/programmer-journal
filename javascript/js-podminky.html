🚦 Podmínky if, else if a else

Krátký úvod

Podmínka umožní programu rozhodnout, který kód se má vykonat.

Program se díky ní může zachovat jinak podle přihlášení, výsledku výpočtu nebo hodnoty formuláře.

🧠 Jak o tom přemýšlet


POKUD je lekce hotová:
    zobraz zelený stav

JINAK:
    zobraz šedý stav

📚 Co se dnes naučíš

  • zapsat podmínku if
  • přidat větev else
  • rozlišit více možností pomocí else if
  • kombinovat podmínky pomocí && a ||
  • použít vnořenou podmínku pouze tam, kde dává smysl
  • pochopit truthy a falsy hodnoty

1️⃣ Základní if


const jeLekceHotova = true;

if (jeLekceHotova) {
  console.log("Lekce je dokončená.");
}

Kód ve složených závorkách se spustí pouze tehdy, když je podmínka pravdivá.

2️⃣ If a else


const jeLekceHotova = false;

if (jeLekceHotova) {
  console.log("Lekce je dokončená.");
} else {
  console.log("Lekce ještě není dokončená.");
}

Vždy se spustí právě jedna z těchto dvou větví.

3️⃣ Else if


const procenta = 75;

if (procenta === 100) {
  console.log("Kapitola je hotová.");
} else if (procenta >= 50) {
  console.log("Jsi za polovinou.");
} else {
  console.log("Pokračuj v učení.");
}

JavaScript kontroluje podmínky shora dolů a zastaví se u první pravdivé větve.

⚠️ Na pořadí záleží


const procenta = 100;

if (procenta >= 50) {
  console.log("Jsi za polovinou.");
} else if (procenta === 100) {
  console.log("Kapitola je hotová.");
}

Druhá větev se nikdy nespustí, protože 100 splňuje už první podmínku.

4️⃣ Porovnání v podmínce


const zadanyPin = "1234";
const spravnyPin = "1234";

if (zadanyPin === spravnyPin) {
  console.log("Přihlášení povoleno.");
}

5️⃣ Více podmínek současně


const jePrihlasen = true;
const maRoliAdmin = true;

if (jePrihlasen && maRoliAdmin) {
  console.log("Zobraz administraci.");
}

Operátor && vyžaduje, aby byly pravdivé obě části.

6️⃣ Alespoň jedna možnost


const jeAdmin = false;
const jeSuperAdmin = true;

if (jeAdmin || jeSuperAdmin) {
  console.log("Uživatel může otevřít správu.");
}

7️⃣ Obrácení podmínky


const jePrihlasen = false;

if (!jePrihlasen) {
  console.log("Nejdřív se přihlas.");
}

8️⃣ Truthy a falsy


const jmeno = "";

if (jmeno) {
  console.log("Jméno bylo zadáno.");
} else {
  console.log("Jméno je prázdné.");
}

Prázdný text "", číslo 0, null a undefined se v podmínce chovají jako nepravdivé hodnoty.

💡 Pro začátek buď přesný

Truthy a falsy zápis je užitečný, ale při učení může být někdy přehlednější výslovné porovnání.

9️⃣ Vnořená podmínka


const jePrihlasen = true;
const role = "admin";

if (jePrihlasen) {
  if (role === "admin") {
    console.log("Zobraz administraci.");
  }
}

Vnoření je možné, ale příliš mnoho úrovní zhoršuje čitelnost.

💻 Kompletní příklad


const pocetHotovychLekci = 9;
const pocetVsechLekci = 12;

if (pocetHotovychLekci === pocetVsechLekci) {
  console.log("JavaScript kapitola je dokončená.");
} else if (pocetHotovychLekci >= 6) {
  console.log("Jsi za polovinou kapitoly.");
} else {
  console.log("Pokračuj další lekcí.");
}

📝 Co si zapamatovat

  • if spustí kód při pravdivé podmínce.
  • else řeší opačnou možnost.
  • else if přidává další možnost.
  • Podmínky se kontrolují shora dolů.
  • && vyžaduje obě podmínky.
  • || vyžaduje alespoň jednu.
  • ! obrací boolean.
