🔖 localStorage a záložky rychlého přístupu

Krátký úvod

Běžná JavaScriptová proměnná po obnovení stránky zmizí. localStorage ukládá malé množství dat přímo v prohlížeči a zachová je i po zavření aplikace.

V této lekci připravíme základy tvého plánovaného rychlého přístupu k právě studovaným lekcím.

🧠 Jak o tom přemýšlet


JavaScriptová proměnná:
  existuje během běhu stránky

localStorage:
  zůstane uložený i po obnovení

localStorage ukládá dvojice: klíč → textová hodnota.

📚 Co se dnes naučíš

  • uložit hodnotu pomocí setItem()
  • načíst hodnotu pomocí getItem()
  • hodnotu odstranit
  • uložit boolean nebo číslo jako text
  • uložit pole objektů pomocí JSON
  • bezpečně načíst data pomocí výchozí hodnoty
  • vykreslit uložené záložky
  • zabránit uložení stejné záložky dvakrát
  • rozlišit dostupnou, dokončenou a budoucí lekci

1️⃣ Uložení textu


localStorage.setItem("uzivatel", "Lubomír");

První hodnota je klíč. Druhá hodnota je uložený text.

2️⃣ Načtení hodnoty


const uzivatel = localStorage.getItem("uzivatel");

console.log(uzivatel);

3️⃣ Když klíč neexistuje


const tema = localStorage.getItem("tema");

console.log(tema);

Výsledkem bude null.

4️⃣ Odstranění hodnoty


localStorage.removeItem("uzivatel");

5️⃣ Vymazání celého localStorage

localStorage.clear();

⚠️ Clear maže všechna data daného webu

V reálné aplikaci ho používej opatrně. Programmer Journal už v localStorage uchovává dokončené lekce.

6️⃣ localStorage ukládá text


localStorage.setItem("pocet", 5);

const pocet = localStorage.getItem("pocet");

console.log(typeof pocet);

Načtená hodnota bude string. Pro výpočet ji můžeš převést: 

const cislo = Number(pocet);

7️⃣ JSON.stringify – objekt na text


const zalozka = {
  nazev: "Podmínky",
  url: "javascript/js-podminky.html",
};

const text = JSON.stringify(zalozka);

localStorage.setItem("zalozka", text);

8️⃣ JSON.parse – text zpět na objekt


const ulozenyText = localStorage.getItem("zalozka");
const ulozenaZalozka = JSON.parse(ulozenyText);

console.log(ulozenaZalozka.nazev);

9️⃣ Pole záložek


const zalozky = [
  {
    id: "js-podminky",
    nazev: "Podmínky",
    url: "javascript/js-podminky.html",
  },
  {
    id: "js-funkce",
    nazev: "Funkce",
    url: "javascript/js-funkce.html",
  },
];

localStorage.setItem(
  "rychly-pristup",
  JSON.stringify(zalozky),
);

🔟 Bezpečné načtení výchozího pole


const ulozeneZalozky =
  JSON.parse(localStorage.getItem("rychly-pristup")) || [];

Pokud klíč neexistuje, použije se prázdné pole.

1️⃣1️⃣ Uložení nové záložky


const zalozky =
  JSON.parse(localStorage.getItem("rychly-pristup")) || [];

const novaZalozka = {
  id: "js-dom-vyber",
  nazev: "DOM a výběr prvků",
  url: "javascript/js-dom-vyber.html",
};

zalozky.push(novaZalozka);

localStorage.setItem(
  "rychly-pristup",
  JSON.stringify(zalozky),
);

1️⃣2️⃣ Kontrola duplicity


const uzExistuje = zalozky.some((zalozka) => {
  return zalozka.id === novaZalozka.id;
});

if (!uzExistuje) {
  zalozky.push(novaZalozka);
}

1️⃣3️⃣ Vykreslení záložek


const panel = document.querySelector("#rychly-pristup");

function zobrazZalozky(zalozky) {
  panel.textContent = "";

  zalozky.forEach((zalozka) => {
    const odkaz = document.createElement("a");

    odkaz.href = zalozka.url;
    odkaz.textContent = zalozka.nazev;

    panel.append(odkaz);
  });
}

Nejdřív panel vyčistíme a potom z uložených dat znovu vytvoříme odkazy.

1️⃣4️⃣ Odebrání záložky


const noveZalozky = zalozky.filter((zalozka) => {
  return zalozka.id !== "js-dom-vyber";
});

localStorage.setItem(
  "rychly-pristup",
  JSON.stringify(noveZalozky),
);

1️⃣5️⃣ Stavy lekcí v Programmer Journalu

lekce-dokoncena
lekce-dostupna

if (jeDokoncena) {

💡 Tvoje plánovaná funkce

V praktickém úkolu nebudeme vytvářet celý systém najednou.

Nejdřív připneme jednu lekci, uložíme ji do localStorage a po obnovení ji znovu zobrazíme.

Další možnosti potom doplníme postupně, abys rozuměl každému kroku.

💻 Zjednodušený kompletní příklad

index.html

script.js


const tlacitko = document.querySelector("#pripnout");
const panel = document.querySelector("#rychly-pristup");

let zalozky =
  JSON.parse(localStorage.getItem("rychly-pristup")) || [];

function ulozZalozky() {
  localStorage.setItem(
    "rychly-pristup",
    JSON.stringify(zalozky),
  );
}

function zobrazZalozky() {
  panel.textContent = "";

  zalozky.forEach((zalozka) => {
    const odkaz = document.createElement("a");

    odkaz.href = zalozka.url;
    odkaz.textContent = zalozka.nazev;

    panel.append(odkaz);
  });
}

tlacitko.addEventListener("click", () => {
  const novaZalozka = {
    id: tlacitko.dataset.id,
    nazev: tlacitko.dataset.nazev,
    url: tlacitko.dataset.url,
  };

  const uzExistuje = zalozky.some((zalozka) => {
    return zalozka.id === novaZalozka.id;
  });

  if (!uzExistuje) {
    zalozky.push(novaZalozka);
    ulozZalozky();
    zobrazZalozky();
  }
});

zobrazZalozky();

📝 Co si zapamatovat

  • setItem() ukládá textovou hodnotu.
  • getItem() ji načítá.
  • Nenalezený klíč vrací null.
  • Objekty a pole převádíme pomocí JSON.stringify().
  • Zpět je obnovíme pomocí JSON.parse().
  • Po změně pole musíme nová data znovu uložit.
  • Po načtení stránky vykreslíme UI z uložených dat.
