⚙️ Funkce, parametry a return

Krátký úvod

Funkce sdružuje několik příkazů pod jedním názvem. Můžeš ji spustit opakovaně a poslat jí různé hodnoty.

🧠 Funkce jako pojmenovaný pracovní postup


název funkce: pozdravUzivatele

vstup:  jméno
práce:  vytvoření pozdravu
výstup: hotový text

📚 Co se dnes naučíš

  • vytvořit deklaraci funkce
  • funkci zavolat
  • předat parametry a argumenty
  • vrátit výsledek pomocí return
  • pochopit lokální proměnné
  • rozlišit funkci, která hodnotu vrací, od funkce, která něco provede
  • zapsat jednoduchou arrow function

1️⃣ Vytvoření a zavolání funkce


function pozdrav() {
  console.log("Ahoj z Programmer Journalu!");
}

pozdrav();

Kód uvnitř funkce se nespustí při jejím vytvoření, ale až při zavolání: pozdrav().

2️⃣ Parametr


function pozdrav(jmeno) {
  console.log(`Ahoj ${jmeno}!`);
}

pozdrav("Lubomír");
pozdrav("Eva");

jmeno je parametr. Hodnoty "Lubomír" a "Eva" jsou argumenty při jednotlivých voláních.

3️⃣ Více parametrů


function secti(a, b) {
  console.log(a + b);
}

secti(5, 3);
secti(20, 10);

4️⃣ Return – vrácení výsledku


function secti(a, b) {
  return a + b;
}

const vysledek = secti(5, 3);

console.log(vysledek);

return pošle výsledek z funkce ven, takže ho můžeš uložit nebo dále použít.

⚠️ Kód za return se nespustí


function test() {
  return "Hotovo";
  console.log("Tento řádek se nespustí.");
}

5️⃣ Funkce bez return


function zobrazZpravu(zprava) {
  console.log(zprava);
}

Tato funkce provede akci, ale nevrací hodnotu pro další zpracování.

6️⃣ Lokální proměnná


function vytvorPozdrav(jmeno) {
  const zprava = `Ahoj ${jmeno}`;
  return zprava;
}

console.log(vytvorPozdrav("Lubomír"));

Proměnná zprava existuje pouze uvnitř funkce.

⚠️ Mimo funkci není dostupná


function vytvorPozdrav() {
  const zprava = "Ahoj";
}

console.log(zprava);

7️⃣ Funkce a podmínka


function stavLekce(jeHotova) {
  if (jeHotova) {
    return "Dokončeno";
  }

  return "Rozpracováno";
}

console.log(stavLekce(true));

Druhý return se použije pouze tehdy, když první podmínka neplatí.

8️⃣ Arrow function


const secti = (a, b) => {
  return a + b;
};

console.log(secti(4, 6));

Arrow function je jiný zápis funkce. Často ho uvidíš u událostí a práce s poli.

9️⃣ Krátká arrow function

const secti = (a, b) => a + b;

U jednoduchého jediného výrazu lze vynechat složené závorky i slovo return.

💡 Pro začátek používej čitelnost

Nemusíš vše zapisovat nejkratším možným způsobem. Důležitější je, abys kódu rozuměl.

💻 Kompletní příklad


function vypocitejProcenta(hotovo, celkem) {
  const procenta = (hotovo / celkem) * 100;
  return procenta;
}

function vytvorZpravu(jmeno, procenta) {
  return `${jmeno} má hotovo ${procenta} % kapitoly.`;
}

const postup = vypocitejProcenta(9, 12);
const zprava = vytvorZpravu("Lubomír", postup);

console.log(zprava);

📝 Co si zapamatovat

  • Funkce je pojmenovaný opakovatelný blok kódu.
  • Parametr přijímá hodnotu při volání.
  • Argument je konkrétní předaná hodnota.
  • return vrací výsledek.
  • Lokální proměnná existuje pouze uvnitř své funkce nebo bloku.
  • Arrow function je alternativní zápis funkce.
