📗 Git log

Krátký úvod

Příkaz git log zobrazí historii commitů v projektu.

Commity jsou seřazené od nejnovějšího po nejstarší.

Díky historii můžeme zjistit, kdy změna vznikla, kdo ji vytvořil a jakou měla zprávu.

🧠 Jak přemýšlet o git log

Každý commit je jako uložená fotografie projektu.

Git log je album, ve kterém jsou všechny fotografie seřazené od nejnovější po nejstarší.

💻 Příklady

  • git log

    Zobrazí podrobnosti včetně ID commitu, autora, data a zprávy.

  • git log --oneline

    Zobrazí každý commit stručně na jednom řádku.

  • git log --stat

    Zobrazí také změněné soubory a počty přidaných a odebraných řádků.

💡 Tip

Pro rychlou kontrolu historie nejčastěji používej git log --oneline.

Z podrobného výpisu se vrátíš do terminálu klávesou q.

⚠️ Nejčastější chyba

Začátečník se někdy lekne, že po příkazu git log nemůže psát další příkaz.

Git pouze otevřel historii v pageru. Do terminálu se vrátíš stisknutím klávesy q.

📝 Co si zapamatovat

  • git log zobrazí historii commitů.
  • Nejnovější commit je nahoře.
  • Každý commit má vlastní identifikátor.
  • git log --oneline zobrazí stručnou historii.
  • git log --stat
  • ukáže také změněné soubory..
  • Z pageru odejdeš klávesou q.
