📗 Git commit

Krátký úvod

Příkaz git commit uloží připravené změny do historie projektu.

Každý commit představuje jeden uložený bod, ke kterému se můžeme později vrátit.

Commit ukládá pouze změny, které jsme předtím připravili pomocí příkazu git add.

🧠 Jak přemýšlet o git commit

Git commit je jako vytvoření uloženého bodu ve hře.

Příkaz git add vybere změny, které chceme uložit.

Příkaz git commit potom z těchto připravených změn vytvoří nový záznam v historii projektu.

💻 Příklady

  • git commit -m "První commit"

    Vytvoří commit s krátkou zprávou „První commit“.

  • git commit -m "Opravena navigace mezi lekcemi"

    Zpráva stručně popisuje, jaká změna byla do historie projektu uložena.

  • git log

    Zobrazí historii commitů včetně jejich identifikátoru, autora, data a zprávy.

  • git log --oneline

    Zobrazí každý commit na jednom řádku, takže je historie přehlednější.

💡 Tip

Zpráva commitu by měla krátce a jasně popsat, co se změnilo.

Místo obecné zprávy „oprava“ napiš například „Opravena navigace mezi lekcemi“.

Jeden commit by měl obsahovat jednu logickou změnu.

⚠️ Nejčastější chyba

Začátečník někdy spustí git commit bez předchozího příkazu git add.

Změny, které nejsou připravené, se potom do commitu neuloží.

Další častou chybou je nesrozumitelná zpráva, například „test“, „změna“ nebo „oprava“.

📝 Co si zapamatovat

  • git commit uloží připravené změny do historie projektu.
  • git commit neodesílá změny na GitHub.
  • Před commitem je potřeba použít git add.
  • Parametr -m umožní napsat zprávu commitu.
  • Zpráva by měla stručně popsat provedenou změnu.
  • git log zobrazí historii commitů.
  • git log --oneline zobrazí zkrácenou historii.
