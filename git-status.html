📗 Git status

Krátký úvod

Git je systém pro správu verzí. Umožňuje ukládat změny v projektu, vracet se ke starším verzím a bezpečně spolupracovat s GitHubem.

🧠 Jak přemýšlet o Gitu

Git je jako ukládání hry.

git add = vybereš, co chceš uložit.

git commit = vytvoříš nový save.

git push = nahraješ save na GitHub.

📚 Co se dnes naučíš

  • co je Git
  • git status
  • git add
  • git commit
  • git push
  • git pull
  • git switch

💻 Příklady

  • git status

    Ukáže aktuální stav projektu a změny v souborech.

💡 Tip

Před každým commitem si spusť git status. Uvidíš, co se opravdu změní.

⚠️ Nejčastější chyba

Zapomenutý příkaz git add nebo neuložený soubor před commitem.

📝 Co si zapamatovat

  • git status ukáže stav projektu.
  • git add připraví změny.
  • git commit uloží změny.
  • git push odešle změny na GitHub.

💻 Vyzkoušej si

git status
git add .
git commit -m "Můj první commit"
git push
