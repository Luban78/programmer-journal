🎨 CSS

Krátký úvod

CSS je jazyk, kterým určujeme vzhled webové stránky.

Pomocí CSS nastavujeme barvy, velikosti, mezery, okraje, rozložení prvků i vzhled stránky na mobilu, tabletu a počítači.

V této kapitole budeme postupovat od připojení prvního stylu až k responzivnímu rozložení a malému praktickému projektu.

🧠 Jak přemýšlet o CSS

HTML určuje, co se na stránce nachází. CSS rozhoduje, jak to bude vypadat.

Selektor vybere prvek a vlastnost určí změnu:

p { color: #14380f; }

Tento zápis vybere všechny odstavce a nastaví jim barvu textu.
