🌐 Formuláře a popisky

Krátký úvod

Formulář sdružuje pole, do kterých uživatel zadává údaje.

Značka <label> vytváří popisek a pomocí atributů for a id ho propojíme s konkrétním polem.

Formulář zapisujeme do značky <form>.

🧠 Jak přemýšlet o tématu

Představ si formulář jako papírový dotazník.

Každé pole musí mít jasný popisek, aby uživatel věděl, co má zadat.

Atribut name pojmenuje údaj, který by se později odesílal.

📚 Co se dnes naučíš

  • jak vytvořit formulář
  • jak propojit label s inputem
  • k čemu slouží atributy for, id a name
  • jak použít textarea
  • jak vytvořit odesílací tlačítko

💻 Příklady

  • <form>...</form>

    Obalí prvky, které patří do jednoho formuláře.

  • <label for="email">E-mail</label>

    Popisek propojený s prvkem, který má id="email".

  • <input id="email" name="email" type="email">

    Pole s jednoznačným ID a názvem odesílaného údaje.

  • <textarea id="zprava" name="zprava"></textarea>

    Víceřádkové pole pro delší text.

  • <button type="submit">Odeslat</button>

    Tlačítko určené k odeslání formuláře.

💡 Tip

Když klikneš na správně propojený popisek label, kurzor se přesune do jeho pole.

U checkboxu kliknutí na popisek zaškrtne nebo odškrtne políčko.

⚠️ Nejčastější chyba

Hodnota atributu for musí být úplně stejná jako hodnota atributu id u příslušného pole.

Duplicitní ID nebo chybějící propojení zhoršují ovládání i přístupnost formuláře.

📝 Co si zapamatovat

  • <form> sdružuje formulářové prvky.
  • label poskytuje jasný popisek.
  • for se propojuje s odpovídajícím id.
  • name pojmenuje odesílanou hodnotu.
  • textarea slouží pro delší text.
