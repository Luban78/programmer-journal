🌐 Tlačítka a inputy

Krátký úvod

Tlačítko vytváříme značkou <button> a vstupní pole značkou <input>.

Atribut type určuje, jaký druh vstupu potřebujeme.

Samotné HTML prvky zobrazí, ale jejich chování později naprogramujeme v JavaScriptu.

🧠 Jak přemýšlet o tématu

Tlačítko je vypínač a input je místo, kam uživatel zadá hodnotu.

HTML připraví ovládací prvky.

JavaScript později rozhodne, co se po kliknutí nebo zadání hodnoty stane.

📚 Co se dnes naučíš

  • jak vytvořit tlačítko
  • jak vytvořit textové, e-mailové a heslové pole
  • jak použít atribut placeholder
  • jak vytvořit checkbox

💻 Příklady

  • <button type="button">Pozdravit</button>

    Běžné tlačítko, které samo neodesílá formulář.

  • <input type="text" placeholder="Zadej jméno">

    Jednořádkové pole pro běžný text.

  • <input type="email">

    Pole určené pro e-mailovou adresu.

  • <input type="password">

    Pole, které skryje zapisované znaky.

  • <input type="checkbox">

    Zaškrtávací pole pro volbu ano nebo ne.

💡 Tip

U tlačítka mimo odesílací formulář používej type="button".

Placeholder je pouze nápověda. Nenahrazuje skutečný popisek pole.

⚠️ Nejčastější chyba

Začátečník někdy očekává, že tlačítko začne samo něco dělat. HTML ho pouze zobrazí.

Bez JavaScriptu kliknutí na běžné tlačítko žádnou vlastní akci neprovede.

📝 Co si zapamatovat

  • <button> vytváří tlačítko.
  • <input> vytváří vstupní prvek.
  • type určuje druh vstupu.
  • Chování prvků budeme později programovat v JavaScriptu.
