🌐 Třídy a ID

Krátký úvod

Atributy class a id umožňují označit konkrétní prvky stránky.

Stejnou třídu může mít více prvků. Jedno ID má být na stránce použité pouze jednou.

CSS podle nich upravuje vzhled a JavaScript vybírá prvky, se kterými má pracovat.

🧠 Jak přemýšlet o tématu

Třída je jako společný dres celého týmu – stejnou třídu může mít více hráčů.

ID je jako jedinečné číslo občanského průkazu – na stránce má označovat jediný prvek.

Samotné atributy vzhled nezmění, ale připraví přesné značky pro CSS a JavaScript.

💻 Příklady

  • <p class="important">Důležitý text</p>

    Třídu important může používat více prvků.

  • <h1 id="main-title">Programmer Journal</h1>

    ID main-title má být jedinečné.

  • <button class="button primary">Uložit</button>

    Jeden prvek může mít více tříd oddělených mezerou.

💡 Tip

Názvy tříd a ID piš bez mezer a diakritiky, například lesson-card.

Název by měl popisovat význam prvku, ne pouze jeho aktuální barvu.

⚠️ Nejčastější chyba

Nejčastější chybou je opakované použití stejného ID u více prvků.

Další chybou je zápis více tříd čárkou. Správně je odděluj pouze mezerou.

📝 Co si zapamatovat

  • class lze použít u více prvků.
  • id má být na stránce jedinečné.
  • Více tříd oddělujeme mezerou.
  • Třídy a ID připravují prvky pro CSS a JavaScript.
